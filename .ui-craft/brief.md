# 多功能 AI 桌宠 · 设计简报

## 1. 产品身份

这是一个 Windows 桌面宠物，而不是以桌宠作图标的效率工具。RGS 角色常驻桌面、响应鼠标与拖动；搜索、快捷启动、设置和 AI 接入作为宠物唤出的附属能力。

## 2. 用户与核心任务

- 面向需要频繁找文件、开应用的 Windows 学习与办公用户。
- 第一价值是“桌面上有一个可识别、可互动的伙伴”。
- 第二价值是点击宠物后，用最短路径搜索或打开快捷项。
- 设置、搜索范围、AI 接入和自启必须渐进披露，不得压过桌宠本体。

## 3. 体验原则

1. 宠物优先：应用启动后首先看到的是角色，不是主窗口。
2. 一击即达：点击角色直接显示紧凑工具气泡并聚焦搜索。
3. 安静陪伴：空闲动画克制，不循环弹窗、不持续吸引注意力。
4. 功能收纳：主页只放搜索、快捷项和明确状态；低频配置进入设置。
5. 本地可信：搜索范围、路径、Key 和诊断信息遵循 PRD 的隐私边界。

## 4. 视觉与语气

- 轻松、克制、有一点手绘角色的温度；不使用游戏商城式高饱和界面。
- 奶油米白承载大部分界面，柔和暖橙用于操作、焦点和桌宠反馈；以低边框、白色表面和暖调阴影建立层级。
- 中文使用 Microsoft YaHei UI，数字与系统标签回退 Segoe UI。
- 文案短、直接、有陪伴感，但不拟人化到妨碍任务完成。

## 5. 约束

- WPF / .NET 8，Windows 10 1809+，不引入新的 UI 依赖。
- RGS 8-Direction Characters 为 MVP 默认资源，4 个角色均可作为内置预设。
- 宠物窗口透明、无边框、置顶；工具气泡必须保持在当前工作区。
- 关键鼠标操作具备键盘路径与可见焦点。

## 6. Learned constraints

- 2026-08-26：用户指出项目偏离主题。后续设计必须把“桌宠”作为产品主体，附加功能不得演变成传统多标签管理器。
- 2026-08-26：工具气泡必须以宠物为唯一定位锚点，优先在宠物上方、空间不足时位于下方；打开期间宠物始终可见。气泡必须有常驻关闭按钮，并支持 Esc、点击外部和再次点击宠物收起，不能因失焦事件竞争而重新弹开。
- 2026-08-27：桌宠只能呈现正面和左右侧面，不使用背对用户的向上方向帧；工具气泡关闭后必须保持关闭，页签选择不得被后台轮询重置，拖动跟随必须由位置事件即时驱动。
- 2026-08-27：单击与双击必须互斥，双击只触发动作；拖动需越过明显阈值。搜索栏在左侧提供范围选择，通配符与 `re:` 正则只在设置中显式开启。宠物可隐藏，但必须通过托盘双击或“显示桌宠”菜单无损恢复。
- 2026-08-27：鼠标离开近距交互半径后桌宠必须回到正面；允许低频随机短语、动作与短距离漫游，但鼠标靠近、拖动、隐藏或打开工具气泡时必须立即中断。AI 内置供应商切换要主动填入端点/模型，结果类别筛选要即时生效，添加入口与文件夹失败必须在当前界面给出可恢复提示。
- 2026-08-28：工具气泡采用奶油米白 `#FAF7F2` 与柔和暖橙视觉系统；区块间距、控件高度、圆角和阴影统一。减少分隔线，仅在搜索便签、快捷项、结果行与设置分组使用轻量背景层级；hover 只允许不改变布局的轻微抬升，并遵循 Windows 动画偏好。
- 2026-08-28：AI 配置必须由当前供应商、端点、模型和 Key 完成连接测试，通过后才能保存；任一编辑使通过状态失效，失败时保留输入且不得覆盖已保存配置。工具气泡标题栏提供独立、可持久化的“常驻”和“置顶”状态按钮，选中反馈不得只依赖颜色。
- 2026-08-29：用户再次反馈全局下拉选择必须同时改变可见文字和实际业务值；后续所有 ComboBox 统一绑定实际选中对象，禁止显示对象字符串或保留双重值绑定。AI 配置要支持命名多配置、当前项切换和旧配置迁移；已保存配置重新测试成功后必须可保存。
