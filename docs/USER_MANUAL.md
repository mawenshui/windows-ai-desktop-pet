## 1. 概览

Windows AI Desktop Pet 是一款常驻桌面的轻量工具入口。它在桌面上显示一个可点击的宠物形象，并在你点击时唤出工具窗口：搜索文件或应用、打开个性化快捷入口、管理待办与一次性提醒、使用已配置 AI 把一句话转换为待确认草稿。本程序仅在你的 Windows 账户内工作，不登录账号，不上传文件，不在未经你同意的情况下扫描磁盘。

## 2. 安装与启动

### 2.1 系统要求

- Windows 10 1809（10.0.17763）或更高版本；推荐 Windows 10 22H2 / Windows 11 23H2；
- x64 处理器；
- 约 200 MB 可用磁盘空间（包含 .NET 运行时自包含）；
- 至少一个用户账户目录（如 `桌面`、`文档`、`下载`）用于搜索。

### 2.2 安装方式

| 方式 | 操作 | 适用人群 |
| :--- | :--- | :--- |
| 双击安装版 | 下载 `windows-ai-desktop-pet-v<版本>-setup.exe`，双击按向导安装 | 希望使用开始菜单、桌面快捷方式、卸载入口的普通用户 |
| 便携版 | 下载 `windows-ai-desktop-pet-v<版本>-portable.zip`，解压到任意目录后双击 `WindowsAiDesktopPet.exe` | 需要复制多台机器或不想写入注册表的用户 |

安装版会写入：

- 程序目录：`%LOCALAPPDATA%\Programs\WindowsAiDesktopPet\`
- 配置目录：`%APPDATA%\WindowsAiDesktopPet\`
- 日志目录：`%LOCALAPPDATA%\WindowsAiDesktopPet\logs\`
- 自启项：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（默认不启用）

### 2.3 首次启动

1. 启动后桌面右下角出现 RGS 宠物形象，系统托盘出现图标；
2. 工具气泡默认收起；点击宠物唤出工具气泡并自动聚焦搜索框；
3. 首次使用时主页显示搜索授权卡，预选“桌面、文档、下载”；可取消任意候选或选择“稍后设置”。只有点击“确认并建立索引”后才会枚举所选目录；**未经确认之前，程序不会索引或读取这些目录**。

## 3. 桌面宠物

| 行为 | 操作 | 备注 |
| :--- | :--- | :--- |
| 唤出工具窗口 | 单击宠物 | 再次点击收起 |
| 触发动作 | 双击宠物 | 只播放动作，不打开或关闭工具气泡 |
| 拖动位置 | 按住宠物并移动至少 12 像素 | 轻微手抖仍按单击处理；已打开的工具气泡即时跟随 |
| 头朝向跟随鼠标 | 在宠物附近移动鼠标 | 近距内仅在 8 像素死区外切换正面/左右侧面；移出约 180px 半径后回到正面，不显示背向姿态 |
| 空闲陪伴 | 约半分钟以上未操作 | 低频随机说一句话、播放动作或短距离漫游；鼠标靠近、拖动或打开工具气泡会立即中断 |
| 切换形象 | 工具气泡 → 设置 → 预设形象 | 可选红帽勇者、方块伙伴、骷髅小队长、森林怪兽 |
| 隐藏宠物 | 右键宠物 → 隐藏桌宠 | 双击托盘图标或托盘右键“显示桌宠”恢复 |
| 退出应用 | 在托盘菜单选择“退出” | 点击宠物、关闭工具窗口均不会结束程序 |

## 4. 工具窗口

### 4.1 唤出与收起

- 点击宠物：工具窗口以角色可见区域为锚点，优先在上方打开，空间不足时在下方打开；窗口始终限制在宠物当前显示器的工作区内；
- 再次点击宠物：收起；
- 按 `Esc`：收起；
- 点击右上角关闭按钮或工具窗口外部：收起；
- 收起不会退出程序，宠物和托盘仍可用；后台单实例监听只在另一次真实启动时重新唤出，不会定时弹回。

标题栏右侧提供两个状态按钮：

- **常驻工具窗口（图钉）**：开启后，点击窗口外部不再自动收起；关闭按钮、`Esc` 和再次点击宠物仍可主动收起；
- **保持窗口置顶（叠层）**：开启后工具气泡显示在普通窗口上方，关闭后按正常窗口层级显示；
- 两项选择会立即保存，重启应用后保持原状态。按钮选中时显示暖橙底色，不只依赖图标颜色表达状态。

### 4.2 页面导航

工具气泡顶部为四项紧凑导航：

| 标签 | 说明 |
| :--- | :--- |
| 主页 | 默认页；包含搜索框、类别筛选、搜索结果与快捷入口 |
| 待办 | 普通待办、独立提醒项、手动编辑、筛选、AI 一句话草稿与确认 |
| 扩展 | 中性占位页，不预先绑定具体业务 |
| 设置 | 桌宠形象、自启、搜索范围、AI 接入与帮助 |

> 提示：“扩展”页当前不包含任何业务功能；“待办”页已经可用。从隐藏状态重新唤出工具窗口时会回到主页；窗口保持打开或随宠物移动时不会自行切页。

工具气泡使用奶油米白背景与柔和暖橙强调色。搜索、下拉框和主要按钮保持 44 像素可操作高度；白色卡片以轻阴影而非大量分隔线区分层级。快捷项与搜索结果在鼠标悬停时只轻微上移，不改变周围布局；关闭 Windows 动画效果后会直接切换状态。

### 4.3 键盘与焦点

- 唤出工具气泡时，焦点默认落在搜索框；
- 搜索结果列表支持上下方向键选择、`Enter` 打开；
- 切换页面：`Ctrl+Tab` / `Ctrl+Shift+Tab`；
- 关闭：`Esc`。

## 5. 待办与提醒

### 5.1 手动创建和维护

1. 点击宠物并切换到“待办”；
2. 点击“新建待办”，填写必填标题；备注、截止日期和提醒日期可留空；
3. 时间使用 `HH:mm`，按当前 Windows 时区解释。不选择日期即表示不设置对应时间；
4. 点击“创建待办”。待办写入 `%APPDATA%\WindowsAiDesktopPet\todos.json`，重启后继续显示；
5. 列表提供“待处理、今天、未来 7 天、已完成”筛选，以及完成、恢复、编辑、10 分钟后提醒、仅取消提醒和删除操作。

“完成”会停止尚未触发的提醒；“恢复”不会自动恢复已经取消或已经投递的提醒。“仅取消提醒”保留待办本身；“删除”会先显示包含标题的确认。

创建独立提醒项时，在新建编辑器勾选“这是提醒项”，设置必填的提醒日期和时间，然后按需开启“桌宠漫游提醒”“桌宠气泡提醒”；两个选项可单独、同时或全部关闭。独立提醒项不使用截止时间，也不提供普通待办的恢复、稍后提醒和仅取消提醒操作。

### 5.2 用一句话创建

1. 先在“设置 → AI 接入”保存一组已经测试通过的配置；
2. 在待办页输入完整句子，例如“明天下午 3 点提醒我提交周报”；
3. 点击“生成草稿”或按 `Enter`；
4. 核对确认卡中的标题、完整年月日、时间、UTC 偏移、备注和操作类型；
5. 点击“确认执行”后才会创建或修改待办。点击取消时不会写入任何数据。

当 AI 草稿只有提醒时间而没有截止时间时，确认卡会明确显示“创建提醒项”；确认后创建独立提醒项，并默认开启桌宠气泡、关闭漫游。需要其他通道组合时，可在确认后编辑该提醒项。

如果只输入“下午提醒我开会”、提供过去时间或出现冲突，页面会显示需要补充的最少信息，不自行猜测。解析失败、AI 未配置、鉴权、限流、网络或超时时，原句会保留，可重试或转为手动填写。

AI 也可解析修改、完成、删除和稍后提醒意图。存在多个同名待办时必须先选择唯一目标；确认卡会显示变更前后内容。执行后可使用页面底部的撤销操作。

### 5.3 提醒与运行条件

- 普通待办的提醒到期后显示页内操作条并提交 Windows 托盘气泡；“完成”更新完成状态，“10 分钟后”只改变下一次提醒，“打开详情”不会自动完成；
- 独立提醒项按该项开关执行桌宠漫游、桌宠气泡或两者。气泡位于桌宠窗口内，会随漫游和手动拖动一起移动；桌宠已隐藏且启用了任一桌宠通道时，应用会先恢复桌宠；
- 独立提醒项投递成功后自动从“待处理”转为“已完成”，同时保留原定提醒时间与已投递状态；投递失败不会自动完成；
- 如果两个桌宠开关都关闭，仍保留托盘提醒；Windows 关闭动画效果时会跳过漫游，但气泡和托盘反馈仍可用；
- 如果应用已经退出或电脑休眠，本版不会在后台准点唤起。下次启动后，尚未投递的一次性提醒会补发一次并标注原定时间；
- Windows 专注助手或账户策略可能隐藏托盘气泡。投递失败会显示可诊断状态，不会冒充成功或自动重复轰炸。

### 5.4 AI 隐私

AI 请求只发送本次输入、当前绝对时间和时区。创建场景不会发送现有待办、搜索历史、文件路径或快捷项。本版不把对话和模型原始响应写入磁盘；“清除 AI 内容”会立即清空当前内存输入、澄清和草稿。

## 6. 主页搜索

### 6.1 添加搜索范围

搜索只覆盖你明确授权的目录。首次卡片只展示并预选 `桌面`、`文档`、`下载` 路径，点击确认前不枚举；确认后才递归建立文件名索引。也可在“设置 → 搜索范围”点击“添加文件夹”。索引跳过隐藏、系统和重解析点，不读取文件正文。

你也可以在“设置 → 搜索范围”里随时添加或撤销目录。状态包括：

| 状态 | 含义 | 建议 |
| :--- | :--- | :--- |
| 等待 | 已授权，尚未开始建立索引 | 点击“重试”或等待自动开始 |
| 准备中 | 正在流式采集名称与路径元数据，并显示累计条目 | 可随时取消；旧索引仍可查询 |
| 可用 | 搜索可命中此范围，并显示条目数与上次成功时间 | 可重新索引 |
| 已取消 | 本次建立索引已停止 | 可重试；上一份成功结果仍保留 |
| 路径失效 | 文件夹已移动、断开或删除 | 重新连接后重试，或移除范围 |
| 失败 | 无读取权限或索引写入失败 | 调整权限后重试；上一份成功结果仍保留 |

移除一个范围后，搜索结果中不再出现该范围的对象；该范围对应的本地缓存和未完成 staging 也会被清理。

### 6.2 发起搜索

1. 先在搜索框左侧选择“全部范围”“仅应用”或一个已授权文件夹；
2. 在搜索框输入名称片段（中英文皆可）；
3. 停止输入 300 毫秒后自动触发查询；
4. 在“全部、文件夹、文档、应用、图片、视频、音频”中选择类别；下拉选择会立即刷新结果，不等待输入防抖；已有关键词时切换搜索范围也会立即重新查询；
5. 双击结果或在结果上按 `Enter` 打开。

### 6.3 排序与匹配

- 默认按文件名包含关系匹配，`%`、`_`、`*`、`?` 等字符按普通文字处理；
- 在设置中开启“`*` 和 `?` 通配符”后，可用 `*.pdf`、`报告-??.docx` 等模式；
- 开启“`re:` 正则表达式”后，以 `re:` 开头输入，例如 `re:^报告-\d+\.txt$`；非法或超时表达式会显示可修改提示；
- 当前只搜索文件或文件夹名称，不用父目录路径制造命中，也不读取文件正文。

### 6.4 搜索状态与错误

| 情况 | 界面提示 | 建议操作 |
| :--- | :--- | :--- |
| 未配置范围 | “请先添加搜索范围” | 打开设置 → 搜索范围 |
| 输入为空 | 显示空状态与提示 | 输入关键词 |
| 范围准备中 | 顶部状态条显示进度 | 等待或继续使用其他已可用范围 |
| 无结果 | “没有匹配项” | 更换关键词、切换类别或检查范围 |
| 正则无效/超时 | 显示语法或超时提示 | 修改 `re:` 后的表达式或关闭正则 |
| 目标失效 | 标记为“失效” | 在设置中重新定位或移除快捷项 |
| 打开失败 | 显示分类原因 | 检查文件权限或系统默认程序 |

## 7. 快捷启动

### 7.1 添加快捷项

1. 在主页快捷入口区域点击“添加入口”选择应用或文件；需要添加目录时点击旁边的“文件夹”；
2. 也可以把文件或文件夹从资源管理器拖到快捷入口区域；一次拖入多个目标时，重复或失效目标会被跳过并提示；
3. 程序会读取目标的系统图标、显示名称和默认描述。应用使用其程序图标，文件使用按扩展名关联的图标，目录使用文件夹图标；
4. 同一目标再次添加会提示“已存在”，你可以取消；取消选择不会产生空记录。

主页会以六列图标网格展示快捷入口；入口较多时只出现纵向滚动条，不会产生横向滚动。没有快捷入口时显示添加引导；添加任一入口后，空状态背景和“文件夹＋”装饰图标会自动隐藏。每个入口只显示正方形图标，悬停可查看名称、描述和完整路径；右键或入口上的“⋯”可打开管理菜单。

### 7.2 自定义图标

- 支持格式：PNG、ICO、JPG、JPEG；
- 建议尺寸：64×64 至 256×256；
- 图标会先验证格式和可解码性，再复制到程序配置目录，源文件被移动或删除不影响显示；读取失败时保留编辑输入并提示，主页显示目标的默认图标。

### 7.3 编辑、删除、排序

- 编辑：修改名称、描述或自定义图标；
- 删除：仅删除本程序中的引用，不会删除、移动或修改目标文件；
- 排序：打开快捷项右侧的“⋯”管理菜单，使用“上移”或“下移”；首项的“上移”和末项的“下移”会自动禁用。

### 7.4 启动与失效

- 单击快捷项启动目标；
- 目标不存在、权限不足或启动失败时显示错误，并提供“重新定位”和“移除”入口；不会自动删除。

## 8. 系统托盘

右键托盘图标弹出菜单：

| 菜单项 | 作用 |
| :--- | :--- |
| 显示桌宠 / 隐藏桌宠 | 切换宠物可见性；隐藏时双击托盘也可恢复 |
| 显示工具窗口 / 收起工具窗口 | 切换宠物旁的工具气泡；打开菜单时按真实可见状态刷新文字与勾选 |
| 设置 | 直接打开工具气泡的设置页（桌宠、自启、搜索范围、AI 接入） |
| 开机自启 | 切换自启开关；打开菜单时重新读取当前账户 HKCU 实际状态 |
| 帮助 | 打开本用户手册的离线版 |
| 退出 | 先处理未保存 AI 修改，再取消搜索、AI 请求和唤醒监听；最多等待 5 秒后结束进程 |

> 关闭工具窗口不会退出程序；只有选择“退出”或通过系统关机流程结束本账户会话，进程才会真正结束。

## 9. 开机自启

- 默认关闭，需要在设置或托盘中手动开启；
- 仅对当前 Windows 账户生效，不写入 `HKLM`，不请求管理员权限；
- 开启后下次登录该 Windows 账户会自动启动并显示托盘，不会自动弹出工具窗口；
- 写入失败（如系统策略阻止）会回滚开关并显示原因。

## 10. AI 接入

> 默认供应商为 **DeepSeek**；内置 DeepSeek / 智谱 / 通义千问 / 月之暗面 / 百度千帆 / 腾讯混元 / 零一万物 / 硅基流动 8 家国内主流预设，以及“自定义（OpenAI 兼容）”入口。选择任一供应商后，**所有字段仍可修改**——预设值只是初始默认值，厂商更新端点或模型时无需等待本程序升级。

### 10.1 添加或修改配置

打开 **设置 → AI 接入**：

1. **选择已保存配置**：如果已有配置，先在“已保存配置”下拉框中选择；选择后会立即加载供应商、地址、模型和凭据，并作为待办 AI 的当前配置。点击“新建”可开始另一组配置。
2. **命名配置**：为配置填写容易区分的名称，例如“工作 AI”或“Qwen 个人”。名称只保存非敏感信息。
3. **选择供应商**：在下拉框中选择一家预设（默认 DeepSeek），或选“自定义（OpenAI 兼容）”以填写自建/代理服务。下拉框会显示供应商名称而非内部对象文本；每次切换内置预设都会把对应“服务地址”和“模型”填入输入框；填入后仍可手动修改。
4. **核对字段**：检查自动填充的“服务地址”和“模型”是否仍是厂商当前推荐值；如已过时或你有特殊要求，可直接改写。
5. **填写 API Key**：在 Key 输入框中粘贴或输入（输入时字符默认掩码）。
6. **测试连接**：字段填写完整后，“测试连接”即可点击；点击后按钮变为“测试中…”，期间不可重复点击，最长 20 秒结束。
7. **查看结果**：测试按钮旁会显示明确结果——
   - **连接正常**，附带耗时并提示可以保存；
   - **连接异常**，附带错误类别与下一步建议。
8. **保存**：只有当前供应商、服务地址、模型和 Key 全部通过测试后，“保存配置”才可点击；连接正常提示出现后按钮会立即刷新为可用，即使这是重新测试的已保存配置。保存后按钮重新禁用，表示没有待保存更改。

修改任一字段（供应商、服务地址、模型、Key）后，先前通过结果立即失效，“保存配置”重新禁用。测试失败时所有输入保持原样，用户可直接修正并重试；失败结果不会覆盖磁盘中的上一份已保存配置。保存多组配置后，可随时从“已保存配置”切换当前使用项，无需重新输入字段；API Key 仍从 Windows 凭据存储读取。

切换配置、新建配置、切离设置页或从托盘退出时，如果存在未保存修改，会显示“保存并继续 / 放弃修改 / 取消”；自动失焦收起不会丢弃输入。点击“删除当前配置”会先显示包含配置名称的二次确认，确认后删除该配置对应的 Windows 凭据、非敏感连接状态、验证结果和内存 Key，再切换到下一条配置或恢复未配置状态。配置名称按去除首尾空格后不区分大小写判重。

### 10.3 凭据安全

- API Key **仅**存储于当前 Windows 账户保护的凭据管理（Credential Manager），不会出现在普通配置文件中；
- 普通配置文件、日志、崩溃报告和错误界面均不会出现 Key 明文或可还原值；
- 清除配置后凭据存储中不再保留可继续使用的旧 Key；
- 切换到其他 Windows 账户无法读取该 Key；
- 测试连接只发送完成测试所必需的最小请求，**不携带搜索词、文件路径、快捷项或待办信息**。

### 10.4 连接异常时的处理

测试显示“连接异常”时，错误类别与建议如下：

| 类别 | 可能原因 | 建议 |
| :--- | :--- | :--- |
| 必填缺失 | 字段未填或格式不合法 | 就地补全或修正 |
| 鉴权失败 | Key 无效或已过期 | 更换 Key |
| 无权限 | 账户对该模型无访问权 | 在服务方检查账户权限 |
| 限流 | 触发频率限制 | 稍后重试 |
| 地址或模型错误 | 服务地址、模型名拼写错误 | 检查设置 |
| 网络不可达 | DNS 或网络故障 | 检查网络 |
| 超时 | 测试请求超过 20 秒 | 稍后重试或检查服务状态 |
| 未知错误 | 服务返回未分类错误 | 查看帮助中的诊断建议 |

> 错误提示只展示类别、时间和建议；不会显示原始响应体、请求头或 Key。

### 10.5 切换供应商

- 切换到任何预设：服务地址与模型自动填入该预设的默认值；Key 字段保留你已填写的值（不会清空）。
- 切换到“自定义”：所有连接字段清空为占位，等待你填写。
- 切换后需先测试当前配置；通过后再点击“保存配置”，否则磁盘中仍保留上一份已保存配置。

- 不会上传搜索关键词、文件路径、快捷项描述、待办或提醒内容；AI 一句话草稿只发送本次输入、参考时间和时区；

## 13. 常见问题

**Q1：工具窗口弹出位置很奇怪，怎么处理？**
A：程序会优先把窗口放在宠物上方，空间不足时改放到下方，并把窗口限制在宠物当前显示器的工作区。如果可用高度仍不足，窗口会缩短并允许内部滚动，不会覆盖角色。

**Q2：搜索“季度复盘”只返回文档不返回应用？**
A：在“全部”类别下查看，或单独选择“应用”类别。匹配基于名称片段，应用名包含“复盘”会进入结果。

**Q3：快捷项点击没反应？**
A：界面会标记为“失效”；点击“重新定位”重新选择目标文件，或“移除”引用。

**Q4：开启开机自启后没生效？**
A：检查是否使用相同 Windows 账户登录；公司账户可能被系统策略限制，此时程序会显示原因。

**Q5：AI 测试连接失败，但 Key 看起来对？**
A：检查服务地址和模型名是否与供应商文档一致；检查账户是否在服务方启用了该模型；必要时在“自定义（OpenAI 兼容）”中按官方示例手填端点。

**Q5b：我想用预设里没有列出的国内厂家或自建代理怎么办？**
A：选择“自定义（OpenAI 兼容）”，按该服务提供的 OpenAI 兼容端点与模型名填写后保存即可。本程序不锁定具体厂商，只要服务兼容 OpenAI `POST /v1/chat/completions` 或 `GET /v1/models` 协议即可连接测试。

**Q5c：选了某个预设后，厂商更新了端点或模型怎么办？**
A：直接把服务地址、模型字段改成最新值即可——本程序不会在保存时把你改过的值覆盖回预设默认值；任何字段修改后状态自动回到“待测试”，重新测试通过后再保存。

**Q6：手册打不开？**
A：先尝试重新安装；如果仍然失败，可暂时从托盘退出后再次启动，程序不会自动打开未确认的网址。

**Q7：想完全清除本程序的本地数据？**
A：退出程序，删除 `%APPDATA%\WindowsAiDesktopPet` 与 `%LOCALAPPDATA%\WindowsAiDesktopPet`；如果是安装版，使用“设置 → 应用 → 安装的应用”执行卸载。
