# Windows AI Desktop Pet 0.16.1 候选说明

日期：2026-09-09。0.16.1 是 0.16.0 的补丁级精进版本，不新增功能入口、依赖或数据 schema。

## 用户可见改进

- 今日安排会自动避让未选中事项已经确认的今天时间块；本地安排从精确的下一刻钟开始。
- AI 只接收勾选事项正文；未选中事项只提供匿名开始/结束时间，不含标识、标题或备注。
- 草稿显示避让的既有时间段数量；应用旧草稿和撤销旧安排分别给出准确的冲突提示。
- GitHub 更新检查和下载只使用已安全保存到 Windows 凭据管理器的令牌，输入框中未保存内容不会发送。
- 临时网络或元数据检查失败时保留此前已发现的新版本和下载入口；明确确认已是最新版本时才清除。

## 兼容性

- `todos.json` 保持 schema 4，`settings.json` 保持 schema 5，无数据迁移。
- 保持 0.16.0 的安装路径、便携版数据位置、更新配置和 AI 配置兼容。
- 未引入第三方包，现有按钮、页面、快捷键和托盘路径保持不变。

## 验证与发布

定向回归 26/26、完整自动化 283/283、system 和 package-smoke PASS，Release 构建 0 警告、0 错误。独立 UI 与窗口性能因应用无法置前而在输入前 FAIL；签名和硬件为 SKIP。详情见[0.16.1 验证报告](release/0.16.1-test-report.md)。本版本仍为候选，不创建标签或 GitHub Release。
