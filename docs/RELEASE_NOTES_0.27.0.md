# Windows AI Desktop Pet 0.27.0 版本说明

日期：2026-10-28。0.27.0 是向后兼容的 MINOR 版本；发行资产与远端验证结果以本轮验证报告及 GitHub Release 为准。

## 本版变化

- 所选待办可直接开始当前时长的专注；活动摘要固定在待办页顶部，显示状态、剩余时间、关联项及暂停/继续。完成专注不会自动完成待办。
- 主页结果类别默认折叠并显示当前选择，授权搜索范围保持可见。
- 设置与托盘展示一致的桌宠状态、原因和恢复入口；专注开始、暂停、继续和完成反馈可在低打扰设置中关闭，重复刷新或重启不会重播状态转换。
- 新增仅本机手动习惯打卡：新增、今日打卡/撤销、停用/启用、累计与近 7 天进度、确认清空。错过一天不扣除记录，不提供等级或角色解锁。
- 可选窗口边缘停留与同屏跟随，默认关闭；目标最小化、消失、跨屏或位置无效时回原工作区底部。专注低打扰时暂停跟随，结束只复核原目标。

## 数据与升级

- 新增 `habits.json` schema 1，手动与每日备份、恢复事务及授权卸载清理均包含习惯；文件损坏或超限时保留原件并禁止覆盖。
- 设置继续使用 schema 7；新增外观与专注反馈字段均有兼容默认值，不涉及新依赖或网络服务。
- 便携版仍使用当前 Windows 账户 AppData。习惯名称和打卡日期属于个人数据；普通备份不包含 API Key。

## 验证状态

0.27.0 完整自动化回归通过 396/396、0 跳过、Release 构建 0 警告和 0 错误。独立 UI 诊断因当前桌面前台条件未形成 PASS；便携、安装、校验和及远端资产以本轮验证报告和 Release 工作流结果为准。
