# Windows AI Desktop Pet 0.26.0 版本说明

日期：2026-09-20。0.26.0 是向后兼容的 MINOR 版本，不是 Alpha、Beta、RC、Preview 或 GitHub Pre-release；正式发布状态以本轮验证报告和 GitHub Release 为准。

## 本版变化

- 设置页新增“桌宠角色库”，把四个内置 RGS 角色与用户导入的本地 2D 角色放在同一原生单选列表；卡片显示真实首帧、角色名、包名、作者和 SPDX 许可。
- 用户选择已解压文件夹后，应用先展示包名、作者、许可、角色数、帧数、预计解码量和短内容指纹；只有明确点击“确认导入”才复制。
- 导入使用同卷 staging，只复制清单声明的 JSON、来源/许可文本和 PNG，复制前后完整复核 SHA-256 内容指纹；重复 ID、源变化或失败不会留下半导入目录。
- 运行时按包和角色原子替换 manifest、帧缓存、FPS 与帧数；活动包失效会回退内置角色。移除当前外部包前先切回内置角色，导入源文件夹不受影响。
- 设置升级为 schema 7 并保留 `.pre-v7.bak`；本地角色包进入手动备份、每日自动备份、恢复事务与用户授权的卸载清理。

## 安全与范围

- 只接受固定 idle/jump、五个原绘方向与可选 death 的声明式 2D PNG 包；未知顶层字段、越界/ADS、链接/重解析点、非法来源或许可均拒绝。
- 单帧最大 512×512、4 MiB；单包最多 1,000 帧、32 MiB 编码数据和 128 MiB RGBA 解码估算，PNG 会完成真实像素解码。
- `source.url` 仅作为来源证据读取，应用不会访问它；角色包没有脚本、进程、网络、搜索、注册表、凭据或任意文件访问能力。
- 本版不提供 ZIP/RAR/7z、在线下载或更新、商城、支付、账号、广告、订阅、商业角色 DLC、3D、音频、云同步或可执行插件。SPDX 与来源摘要不是权属审核，导入者仍需确认素材权利。

## 升级与使用

- 0.25.x 设置会自动升级到 schema 7；既有 `rgs-8dir` 与首选角色保持不变。
- 角色包根目录需要包含 `pet.json`、`SOURCE.txt`、`License.txt` 和 `frames/`；应用不直接读取压缩包。
- 下载 `windows-ai-desktop-pet-v0.26.0-portable.zip` 或 `windows-ai-desktop-pet-v0.26.0-setup.exe` 时，应使用同一 Release 的 `SHA256SUMS.txt` 校验。
- 便携版继续使用当前 Windows 账户的 AppData，不是数据随 ZIP 移动模式。
