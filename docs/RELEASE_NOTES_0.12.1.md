# Windows AI Desktop Pet 0.12.1 发布说明

## 重点修复

- 修复工具窗口启用失焦自动收起时，下拉弹层可能被误判为外部窗口，导致选择尚未提交就收起并仍显示默认项的问题。
- 主页、待办和设置页的八个下拉框统一保留 WPF 原生模板与对象级 `SelectedItem` 语义；展开期间暂停自动隐藏，选择后显示值与业务值同步保持。
- 改进键盘行为：存在展开下拉时，第一次按 Esc 只关闭下拉框，第二次才收起工具窗口。
- 回归覆盖扩展到搜索范围、结果类别、待办筛选、AI 操作目标、主题、新建 AI 模板、已保存 AI 配置和供应商八个控件，并覆盖自动隐藏竞争条件。

## 验证结果

- 自动化逻辑与 WPF 交互测试：173 项，0 失败，0 跳过。
- 项目结构、SemVer、UTF-8 和敏感文件名校验通过。
- 独立桌面 UI runner 需要可见、稳定的交互式 Windows 桌面；当前会话跨桌面输入不可用时按实际结果报告，不将程序化选择冒充真实输入通过。
- 物理多屏、不同缩放、Explorer 重启、显示器热插拔、休眠和可信代码签名继续按实际环境报告 PASS/FAIL/SKIP。
