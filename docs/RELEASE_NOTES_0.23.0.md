# Windows AI Desktop Pet 0.23.0 候选说明

日期：2026-09-14。0.23.0 是“提醒中心聚焦与静默优化”候选版本，不是已发布的稳定 Release。

## 本版变化

- 提醒中心增加只在本机当前通知快照中匹配标题的查找，并提供待处理、历史、全部三分段计数和处理优先、最近记录两种稳定排序。
- 无记录、当前分段为空和查找无匹配分别提供唯一恢复动作；查询不改变分段计数，也不进入存储、日志或 AI 上下文。
- 提醒记录改为原生单选列表，刷新按稳定通知 ID 恢复仍可见目标；完成、稍后和详情集中到列表下方的统一操作带。
- 列表支持方向键/Home/End、Enter/F2 详情、`Ctrl+Enter` 完成、`Ctrl+Shift+Enter` 稍后与双击详情；动作只作用于当前选中提醒。
- 类型、恢复来源、投递状态、选中摘要和目标动作增加非颜色文字及目标化 UI Automation 名称，紧凑按钮不低于 36 DIP。
- 静默时段改为显式草稿，增加严格 `HH:mm` 实时校验、夜间/午休/关闭预设、未保存/已保存状态和独立提醒反馈。
- 清理历史显示实际可清数量，继续保留排队/已提交业务提醒与业务待办。

## 升级与兼容

- 设置 schema 保持 5，待办 schema 保持 4，通知 schema 保持 1，快捷入口 schema 保持 1，不新增数据迁移。
- 提醒查询、筛选、排序、选择、计数、摘要、静默草稿和页面反馈只在进程内保留，不进入备份、诊断、日志或 AI 请求。
- 到期持久排队、静默合并、系统通知提交、普通待办不自动完成、独立提醒完成、历史清理和并发目标校验继续复用既有语义。
- 不新增外部依赖、网络权限、云同步、账号或遥测。

## 发布边界

候选测试、资产哈希和 PASS/FAIL/SKIP 见[0.23.0 验证报告](release/0.23.0-test-report.md)。前台真实 UI、性能、安全存储、代码签名、物理多屏/缩放、休眠/时区、Explorer 重启、真实覆盖升级、提交/推送和远端 Release 必须分别验证；任一必需门禁不完整时不得发布为稳定版本。
