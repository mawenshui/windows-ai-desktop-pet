## 1. 产品定位与范围

桌宠是常驻入口，点击后进入紧凑工具窗，完成找文件、启动常用目标、维护待办和提醒。AI 是可选的结构化录入助手，不是手动功能的前置条件。产品按单机、单 Windows 账户运行，无登录、云同步或遥测上传实现。

当前页面为主页、待办、维护、设置。保留原需求编号用于追踪，但不再把待办和维护描述为占位页。下文“已接入”表示存在产品调用链，不代表实机验收已通过；“部分”表示已有基础而流程未齐；“候选”未进入当前用户能力。

### 1.1 当前能力边界

- 搜索只处理用户授权目录，不扫描全盘。名称和相对路径索引始终可用；用户可单独开启受控正文搜索，只读取不超过 128 KiB 的 `.txt`/`.md`，每范围最多 1,000 个文件和 16 MiB。结果支持固定、用户同意后的本地最近使用排序，以及选中后的打开、资源管理器定位、复制路径和加入快捷入口。应用入口从当前用户开始菜单及 App Paths 获取，不保证覆盖全部应用。
- AI 有多组命名配置、加密完整配置包、无 Key 兼容迁移、预设导入及确认写入的待办草稿。完整包迁移全部配置、当前项、自定义 Provider 和 Key，导入后立即启用；模型列表验证与主动确认后运行的生成验证分开。
- 提醒页面支持一次性/日历重复、多次时间、时区、仅此次或整条编辑、摘要/预览、AI 规则草稿及持久提醒中心。中心提供标题本地查找、三筛选计数、两排序、原生单选/统一操作、列表快捷键，以及有草稿、校验、预设和保存反馈的静默设置。退出/关机期间不提供进程外准点提醒。
- 待办页提供“清单 / 复盘”二级视图；复盘从本地待办投影当天轨迹、自动保存独立正文、跨日冻结只读快照，并由用户显式导出单日 Markdown。复盘不进入 AI、搜索索引、日志、诊断或遥测。
- 待办页的“专注陪伴”可关联当前未完成普通待办或无关联开始，支持 5～180 分钟、暂停、继续、提前结束和到时确认；结果不自动完成 Todo，并在当日复盘与 Markdown 中本地聚合。
- 专注运行和暂停时桌宠进入低打扰状态；可选点击穿透与同屏真全屏自动隐藏均默认关闭，并提供托盘恢复路径。检测不读取其他窗口内容或持久化活动时间线。
- 四个 RGS 角色以真实首帧卡片展示，选择先持久化再运行时应用，失败保持原角色；不新增图片、音频、模型、外部角色下载或角色卡预览动画。
- 维护有模块预览、依赖成组备份、重启事务恢复及中断回滚、诊断和缓存清理；交互卸载可选清理已知个人数据。跨设备路径需重新定位，Key 不迁移。
- 全局快捷键默认从任意普通窗口打开搜索或快速新建待办；用户可停用或改键，冲突时整组回滚，托盘始终保留等价入口。
- 每日本地自动备份默认启用、24 小时最多一次并有保留上限；备份不含 Key、搜索索引和日志，失败不删除旧备份。
- 正常启动异步检查一次 GitHub Release；检查失败不阻止桌宠使用，也不清除此前已发现的可下载版本。设置只保留运行期间周期检查和 1～168 小时间隔，网络线路由应用自动选择。
- 固定公开仓库的稳定 Release；用户无需填写加速模板、代理地址或 GitHub Token。官方元数据失败时自动切换内置 API 线路，安装器下载按内置线路及官方地址逐级恢复；安装器必须同时满足 Release digest（存在时）与 SHA-256 清单，且仅在用户确认后启动。
- RGS 四种 2D 预设已接入。受控纯文本正文检索已接入；PDF/Office、OCR、语义检索和外部宠物包导入未接入，通用聊天、可执行插件、云同步、3D 和角色商城不在产品范围。

### 1.2 隐私、数据及权限

Key 保存在 Windows Credential Manager，普通配置只存非敏感字段及凭据引用。查询词、完整路径、待办/AI 原文、鉴权头不写入默认日志。个人数据按当前账户保存，便携版不默认改为程序旁存储。

目录候选在确认前不枚举文件；正文读取需在设置中单独开启。停用正文搜索或撤销范围必须清除对应派生正文，过期任务不能恢复已撤销数据；正文、摘要和搜索词不进入日志、诊断、备份或 AI 请求。单项 AI 草稿只发送当前主动输入的文本、时间/时区提示及解析指令；今日安排只发送用户明确勾选的最多 12 项正文及时间/时区，未勾选事项只可提供不含标识或正文的匿名占用时间段用于避让。AI 写操作必须先展示草稿和明确目标，由用户确认后执行。

备份不含 Key，但含路径和待办等个人数据；诊断只导出白名单字段。任何新增外部服务、依赖、角色素材或数据上传都需独立评估，不能因写了 FeatureSettings 字段就启用。

### 1.3 质量目标与观察指标

性能预算来自 `config/performance-budgets.json`：20,000 条、200 次查询，搜索首屏 P95 ≤1 秒，窗口唤出 P95 ≤300 ms，冷启动 ≤3 秒；空闲 CPU ≤2%、工作集 ≤300 MB、拖动 ≥30 FPS、句柄 ≤1,200。预算是验收目标，不是已经达到的当前统计。

稳定性目标保持不少于 1,000 会话下无崩溃率 ≥99.5%；首次任务可用性目标保持 20 名目标用户五项核心任务各 ≥95%。尚无对应真实统计，不标记达标，也不因此加入遥测。用户研究和任何采集方案必须单独确认。

## 2. 信息架构与核心路径

| 入口 | 页面 / 结果 |
| :--- | :--- |
| 单击桌宠 | 唤出主页；搜索框获得焦点 |
| 主页 | 搜索授权、范围、关键词、类别、结果操作、快捷入口；搜索框与结果可连续键盘移动 |
| 待办 | 新建/手动清单优先，专注陪伴、清单/复盘、单项 AI 草稿与今日安排按需展开，提醒操作 |
| 维护 | 手动备份/恢复、每日自动备份、诊断、缓存清理 |
| 设置 | 五项页内目录；真实首帧角色卡、外观/动作、低打扰、自启、全局快捷键、更新、搜索范围/匹配、AI 配置、手册 |
| 托盘 | 桌宠/工具窗可见性、专注暂停/继续/结束、恢复桌宠交互、立即搜索、快速待办、设置、自启、帮助、提醒动作、退出 |

常驻与置顶相互独立；收起不是退出。一般桌宠唤出进入主页，托盘设置/提醒等定向入口按对应页面处理。再次打开不会创建第二套工具窗口。

## 4. 关键边界与错误处理

所有页内选择需同步可见项及业务值，保留键盘选择、焦点轮廓和可访问名称。已保存 AI 配置切换先处理未保存草稿；测试期间编辑使结果失效，失败不覆盖旧配置。模型列表请求成功不能宣称已验证结构化任务能力。

范围重建失败/取消保留旧结果，撤销取消对应任务并删除名称、正文及偏好索引；watcher 恢复监听、子树更新和 Revision 分页有回归。正文全量重建使用暂存提交，通配符/正则只匹配元数据，元数据命中优先于仅正文命中。普通待办与独立提醒分开；先持久排队再推进时间，宿主接受不等于用户已读。重复规则保持所选时区钟点，静默跟随当前 Windows 时区；DST 缺失钟点顺延、重复钟点取较晚，漏触发汇总一次。备份验证后重启切换，失败回滚不能宣称全量成功。全局按键占用不得留下部分注册；自动备份未成功前不得执行保留清理。

专注会话的 UI 秒级刷新不等于秒级写盘；状态转换、恢复校准和退出检查点才持久化。专注与点击穿透、全屏隐藏分别维护原因，退出全屏不得取消专注或覆盖用户手动隐藏。关联 Todo 被删除时历史只保留 ID，界面显示稳定占位且不得泄漏旧标题。角色切换必须在设置写入成功后才改变运行时，资源异常始终回退到可显示角色。
