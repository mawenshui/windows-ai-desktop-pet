## 1. 目标与边界

本轮继续优化已有功能，不引入新页面、账号、云同步、遥测、外部资源或运行时依赖。目标是让高频搜索、快速记待办、键盘导航、无结果恢复、待办编辑和维护反馈具备更短路径、更明确状态与可恢复操作，同时保持桌宠是唯一常驻主体，工具窗仍是紧凑附属入口。

版本选择 `MINOR`：新增向后兼容的全局键盘入口、可操作空态、待办编辑保护和统一撤销能力。设置 schema 维持 5，待办 schema 维持 4，快捷入口 schema 维持 1；新增状态均为进程内视图状态。

设计沿用 `.ui-craft/brief.md` 与 `.ui-craft/tokens.md`：奶油米白和暖橙、原生 WPF 控件、可见焦点、短集合页内单选、紧凑文字按钮不低于 36 DIP。签名细节是“可操作状态带”：无结果和未保存编辑都直接给出下一步，不把用户留在死端。

## 3. 状态与交互设计

### 3.1 导航优先级

`Ctrl+N`、`F1`、`Alt+1`～`Alt+4` 与 `Ctrl+L` 都由工具窗统一键盘入口处理。`Ctrl+N` 和直接切页继续调用 `TrySelectTab`，不能绕过 AI 未保存配置保护。Esc 的优先级固定为：待办页内编辑确认 → 主页清空查询 → AI 未保存保护 → 收起工具窗。

### 3.2 搜索恢复

无结果不是纯文字终点。恢复面板保留当前错误或空态说明，并在存在查询、类别过滤或单范围时提供“重置搜索条件”；另一入口定位到设置页的搜索分组。重置动作直接写入一组视图字段，取消旧查询后只启动一次立即搜索，避免连续三次无意义请求。

结果数量与通用操作状态分开：标题旁只显示搜索生命周期数量；底部状态仍显示打开、复制、索引和错误反馈。所选摘要不显示完整路径，只显示列表内已公开的名称、类型、大小与相对序号。

### 3.3 待办编辑与撤销

编辑器打开时保存一份字段快照；标题、备注、类型、日期时间、提醒通道、重复、时区、额外时间和“仅此次”共同参与脏状态。首次请求取消且存在修改时只展开页内确认带，不关闭编辑器；继续编辑收起确认带，放弃修改才关闭。

最近一次撤销复用现有内存快照机制并扩展到手动操作。撤销只允许覆盖尚未再次修改的目标；失败时保留当前数据并给出稳定提示。删除仍会同步处理待提交通知，但撤销恢复事项后由现有存储变更与提醒调度重新计算未来触发，不恢复已投递通知记录。

### 3.4 可访问反馈

可操作控件使用原生 Button、ListBox、CheckBox 和 Expander。图标或省略号按钮必须有包含目标的可访问名称；状态变化使用可见文字和 `AutomationProperties.LiveSetting="Polite"`。颜色只承担辅助层级，错误、选中、失效与未保存状态都同时使用文字、图形或明确动作。

## 4. 测试计划

1. `ShellNavigationTests` 与 WPF 生命周期测试覆盖 `Ctrl+N`、`F1`、Esc 层级、`Ctrl+Enter`、快捷键提示和焦点。
2. `HomePageExperienceTests` 覆盖单次重置、结果数量和选择序号；布局测试覆盖可操作空态及快捷入口可访问名称。
3. `TodoViewModelTests` 覆盖筛选摘要、空态动作、编辑脏状态、放弃确认与手动操作撤销；`TodayPlanTests` 覆盖前 12 条与清除选择。
4. XAML 合同测试覆盖 36 DIP、可见时间格式、live region 和维护稳定错误文案；生命周期测试验证真实绑定与命令状态。
5. 完成实现后运行两次 `scripts/test.ps1 -CI`，再运行独立系统/UI/性能与打包烟雾入口；无法前台输入、签名或物理环境项目如实 FAIL/SKIP。

## 5. 验收标准

| ID | 验收要求 |
| :--- | :--- |
| AC-UX-210-01 | `Ctrl+N`、`F1`、`Alt+1`～`Alt+4`、`Ctrl+L` 均从工具窗生效，且直接导航不绕过 AI 未保存保护 |
| AC-UX-210-02 | Esc 在编辑器、搜索框、普通页面三种状态下按既定优先级执行，焦点和输入不会被意外丢失 |
| AC-UX-210-03 | 无结果面板至少提供一个有效恢复动作；重置同时恢复查询、类别和范围并只触发一次最终刷新 |
| AC-UX-210-04 | 搜索数量与选中序号在首次查询、刷新、加载更多和条件变化后保持一致，不显示完整路径 |
| AC-UX-210-05 | 待办筛选摘要与空态动作匹配当前筛选，新建后不会把用户留在看不到新事项的筛选 |
| AC-UX-210-06 | 编辑器任一字段变化产生未保存状态；取消先显示页内确认，继续编辑不丢数据，放弃才关闭 |
| AC-UX-210-07 | 手动新建、修改、完成、恢复、稍后、取消提醒和删除均可撤销最近一次，目标已再次修改时拒绝覆盖 |
| AC-UX-210-08 | 今日安排一键选择最多 12 条且可全部清除，选择变化使旧草稿失效，未选正文仍不进入 AI 请求 |
| AC-UX-210-09 | 紧凑操作不低于 36 DIP；页签、快捷入口、状态、错误、提醒和时间格式可由键盘与 UI Automation 理解 |
| AC-UX-210-10 | 维护异常不显示原始异常正文、堆栈或完整路径；失败提示包含保留内容和下一步建议 |

## 6. 非目标与发布边界

- 不新增系统级快捷键；`Ctrl+N` 和 `F1` 只在工具窗激活时处理。
- 不把编辑草稿、撤销记录、筛选计数或键盘提示写入配置文件。
- 不新增待办批量删除、云端恢复、跨重启撤销或通知已读语义。
- 不以进程内 WPF 测试替代真实前台输入、多屏/缩放、休眠/时区、Explorer 重启或代码签名。
- 完整门禁未通过时只能作为候选，不创建稳定标签或 GitHub Release。
