# Windows AI Desktop Pet 0.15.0 候选说明

日期：2026-09-08。0.14.0 → 0.15.0 是向后兼容的功能扩展 MINOR。当前为候选版本；完整发布门禁尚未全部通过，没有创建 `v0.15.0` 标签或 GitHub Release。

## 新增

- 设置 → AI 接入新增“导出完整配置”和“导入完整配置”，迁移全部已保存配置、活动项、连接状态、自定义 Provider 预设、启用状态和 API Key。
- 完整包使用 `.aipet-ai-config`，导入先显示来源版本、导出时间、配置数、含 Key 数、Provider 数和即将启用的配置；用户确认后整体替换 AI 配置，导入完成即可使用。
- 新增独立迁移口令对话框，导出要求至少 10 个字符并二次确认；口令不保存，导入错误或文件被篡改时不显示内容、不写配置。
- 原无 Key JSON 导入导出和单独 Provider 预设导入继续保留，供公开模板或低敏迁移使用。

## 安全与恢复

完整包的内层 schema 1 使用 PBKDF2-HMAC-SHA256 310,000 次派生 256 位密钥，再用 AES-256-GCM 加密和认证。外层只保存格式、KDF/加密参数、随机盐、nonce、tag 和密文，不保存凭据目标名。文件上限 4 MB，最多 100 组配置和 32 个自定义 Provider。

导入先校验整个包，为每组配置创建新的本机凭据目标，全部 Key 写入成功后才保存 Provider 预设和普通设置。任一步失败会清理本次已写的新凭据并保留原配置；提交成功后再清理旧凭据。普通设置、日志、诊断、测试快照和每日备份继续排除 Key。

## 升级说明

设置 schema 保持 4，不需要迁移现有普通配置。原 AI 配置和凭据继续可用。完整导入会替换目标设备的全部 AI 配置和自定义 Provider 预设，其他应用设置不变；确认前应核对预览。迁移文件包含可解密的 Key，应与口令分开保存并在不再需要时安全删除。

## 验证边界

自动化、打包、烟雾、签名、独立 UI 和物理设备的当次结果见[0.15.0 验证报告](release/0.15.0-test-report.md)。真实桌面上的口令对话框、文件选择、取消、跨 Windows 账户凭据写入和导入后实际服务调用仍需独立见证；没有证据时不得写为 PASS。
