# 0.18.0 候选说明

日期：2026-09-12。0.18.0 完善搜索结果的日常操作闭环；能否作为稳定版本发布以[本次验证报告](release/0.18.0-test-report.md)为准。

## 新增与改进

- 单击或使用键盘选择搜索结果后，主页显示“打开”“定位”“复制路径”“加入快捷入口”操作区，并保留双击与 Enter 打开。
- 打开使用 Windows 默认关联程序；定位在文件资源管理器中选中目标，驱动器根目录直接打开。
- 复制路径只在用户主动操作时写入剪贴板，不进入设置、诊断、日志或 AI 请求。
- 加入快捷入口复用现有名称、类型、系统图标、持久化和重复检查规则。
- 失效结果会禁用打开、定位和加入快捷入口，但仍允许复制路径用于排查；不会自动删除索引记录或原文件。
- 手动重查或索引刷新后按范围与完整路径恢复同一选择；修改关键词、类别、范围、字段或匹配模式会清除旧选择。

## 兼容与隐私

- 版本由 0.17.0 按 MINOR 升级至 0.18.0。
- 设置继续使用 schema 5，待办继续使用 schema 4，不需要数据迁移。
- 没有新增运行时依赖、网络请求、账号、遥测、文件修改或商业化功能。
- 现有授权搜索、受控正文、快捷入口、AI 配置、待办、维护和更新数据保持兼容。

## 验证说明

系统动作参数、异常隔离、失效命令状态、快捷入口复用、刷新选择恢复、条件变化清除和 WPF 可访问入口已加入自动化。完整 CI 297/297、system 和 package-smoke 为 PASS；独立 UI 与窗口性能受当前桌面前台锁限制为 FAIL，签名和物理设备为 SKIP。因此 0.18.0 只提供候选资产，不作为稳定 Release。完整结果见[0.18.0 验证报告](release/0.18.0-test-report.md)。
