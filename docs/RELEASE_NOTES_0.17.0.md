# 0.17.0 候选说明

日期：2026-09-11。0.17.0 将受控本地文本正文搜索接入现有授权搜索，并保持默认关闭。本文描述产品行为；能否作为稳定版本发布以[本次验证报告](release/0.17.0-test-report.md)为准。

## 新增与优化

- 设置 → 搜索范围新增“文件正文搜索（可选）”。用户单独开启后，应用为现有授权文件夹后台建立正文索引，并显示索引数、跳过数和读取量。
- 只读取不超过 128 KiB 的 `.txt` 和 `.md`，支持严格 UTF-8 与带 BOM 的 UTF-16；每个授权范围最多 1,000 个正文文件和 16 MiB。隐藏、系统、链接、二进制、非法编码、超限或不可读文件会跳过。
- 普通文字查询可补充正文结果；名称或相对路径的完全、前缀和包含匹配保持更高相关性。仅正文命中显示“正文连续包含”和最多 120 字符的折叠空白摘要。
- `*`/`?` 通配符和 `re:` 正则继续只匹配用户选择的名称或相对路径字段。范围、类别、固定、最近使用、分页和索引修订刷新继续生效。
- 全量名称与正文索引分别暂存并在同一范围提交；取消或失败不提交正文半成品。文件监视器同步新增、修改、删除和移动。
- 停用正文搜索会立即清空正文、暂存和统计表；开关代次阻止旧任务重新写入。移除范围会清除该范围的名称、正文、统计和偏好，不删除原文件。

## 数据与隐私

- `settings.json` 保持 schema 5，复用已有、默认 `false` 的 `features.enableContentSearch`；无配置迁移。
- 正文索引存于 `%APPDATA%/WindowsAiDesktopPet/index.db` 的派生表，SQLite 使用 `secure_delete=ON`。清除数据库行不代表对底层物理介质进行安全擦除。
- 正文、摘要、查询词和完整路径不进入日志、白名单诊断、普通/自动备份、更新请求或 AI 请求。搜索索引仍从维护备份中排除，并可通过缓存重建整体删除。

## 未包含

PDF、Office、图片 OCR、压缩包、邮件正文、语义/向量搜索、云端索引和用户自定义解析器没有接入。外部 2D 宠物包仍是隔离原型。

## 验证状态

受控正文的编码、二进制、资源上限、排名、摘要、通配符/正则分流、范围清除、停用竞态、watcher 更新、设置持久化和 WPF 可访问入口已加入自动化。完整 CI 289/289、system 和 package-smoke 为 PASS；独立 UI 与窗口性能受当前桌面前台锁限制为 FAIL，签名和物理设备为 SKIP。因此 0.17.0 只提供本地候选资产，不作为稳定 Release。完整结果见[0.17.0 验证报告](release/0.17.0-test-report.md)。
