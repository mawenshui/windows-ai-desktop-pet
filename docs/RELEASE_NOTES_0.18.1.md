# 0.18.1 候选说明

日期：2026-09-12。0.18.1 在 0.18.0 功能基础上统一完善常用界面的可执行状态和反馈；能否作为稳定版本发布以[本次验证报告](release/0.18.1-test-report.md)为准。

## 改进

- 搜索词非空时显示一键清空按钮；清空后取消旧选择、刷新结果并把焦点留在搜索框，类别和范围保持不变。
- 搜索结果加入快捷入口后立即显示“已在快捷入口”并禁用重复提交；快捷入口数据变化后实时刷新状态。
- 全局快捷键、自动备份和更新检查分别跟踪已保存基线，按钮明确显示“有修改”或“已保存”，无修改时不重复写盘。
- 设置校验或写入失败时保留用户输入和未保存状态；GitHub 令牌仍与普通设置分离，只保存在 Windows 凭据管理器。
- 快捷入口管理器显示当前结果数和选择数，并按空选、单选、多选、排序边界和扫描状态启用分组、固定、重新定位、排序、移除、撤销与扫描操作。
- Delete 键复用现有批量移除预览，只移除快捷引用，不删除原文件；扫描期间冻结修改并允许取消。
- 待办编辑器只有在标题非空白时才允许保存，标题输入和编辑器开关会即时刷新按钮；现有日期、时间、重复与提醒校验保持不变。

## 兼容与隐私

- 版本由 0.18.0 按 PATCH 升级至 0.18.1。
- 设置继续使用 schema 5，待办继续使用 schema 4，快捷入口继续使用 schema 1，不需要数据迁移。
- 没有新增运行时依赖、网络服务、权限、账号、遥测、文件修改或商业化能力。
- 搜索清空与管理状态只存在于当前界面会话；查询词、完整路径、待办内容和凭据仍不进入默认日志或诊断。

## 验证说明

升级前完整 CI 已完成 Release 构建 0 警告、0 错误及 302/302 自动化测试 PASS。版本升级后的完整 CI、打包、烟雾、独立 UI、性能、签名、硬件和远端状态以[0.18.1 验证报告](release/0.18.1-test-report.md)为准。
