# 0.23.0 功能扩展计划

## 实施顺序

1. UX-230-01～05：提醒行投影、标题查找、筛选计数、稳定排序和可恢复空态。
2. UX-230-06～10：原生单选、刷新恢复、选择摘要、统一操作带和状态化动作。
3. UX-230-11～13：列表快捷键、非颜色状态和目标化可访问名称。
4. UX-230-14～18：静默草稿、实时校验、快捷预设、保存反馈、历史计数和提醒区 live region。
5. 自动化测试、版本、文档、打包与候选验证。
