## 交互范围

1. 待办清单所选未完成普通待办有“开始专注”快捷命令，使用当前有效时长并沿用同一 FocusSessionService 状态机；活动摘要固定在待办页顶端，保留剩余时间、关联项、暂停/继续。结束仍不自动完成待办。
2. 主页搜索类别默认折叠，在标题显示当前类别；已授权范围保持直接可见，折叠只改变布局，不改变索引、授权或查询逻辑。
3. 桌宠状态由统一文案函数给设置和托盘显示，明确手动隐藏、同屏全屏隐藏、点击穿透、专注暂停/运行及相应恢复入口。
4. 开始、暂停、继续仅在会话状态转换时显示桌宠文字反馈，完成沿用一次结果反馈；开关在低打扰设置中显式保存，正式提醒优先。进程启动读取既有会话只建立状态基线，不重播开始/暂停/继续。
5. 本机 `habits.json` schema 1 保存手动习惯与日期，一天至多一次，可撤销、停用/启用及确认清空；展示累计天数与包括今天在内的近 7 天。跨日刷新与按钮操作先核对当前日期，不自动打卡、扣除旧记录、生成等级或解锁角色。文件限制 8 MiB、100 项、每项 3650 天；损坏或超限时保留原件并拒绝写入。手动/自动备份、恢复事务和授权卸载清理纳入 Habits 模块。
6. 窗口边缘停留默认关闭。只读取可见非本进程窗口的几何与显示器，拖动释放后命中上边缘才附着；同屏有效目标移动时跟随。最小化、销毁、跨屏或几何不可用时落到原工作区底部；用户拖动立即脱离。专注低打扰期间暂停跟随，保留原句柄；结束时只复核原窗口，失效即回落，不重新扫描其他窗口。

## 数据、隐私与验收

- 习惯不发送给 AI，不进入搜索索引、默认日志或诊断。备份包含习惯名称与日期，需按个人数据保管；无 Key。
- 窗口边缘探测不读取标题、正文、路径、截图、剪贴板、输入或进程内容，不保存目标窗口历史。
- 单元与进程内 WPF 回归覆盖跨午夜、同日幂等、损坏/容量、备份恢复、Esc 取消、反馈状态转换、类别展开绑定、边缘几何与低打扰附着状态。物理多屏和不同缩放为可选实机诊断，结果按实际环境记录。
- 发布要求原样 `scripts/test.ps1 -CI`、便携运行、安装、安装后启动、卸载和 SHA-256；在通过与远端资产验证前只称源码候选。
