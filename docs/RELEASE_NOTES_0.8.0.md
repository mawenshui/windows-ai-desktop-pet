# Windows AI Desktop Pet 0.8.0 发布说明

发布日期：2026-08-28  
状态：发布候选

## 新增

- “计划”页升级为完整“待办”页，支持待处理、今天、未来 7 天、已完成筛选。
- 支持手动创建、编辑、完成、恢复、删除，以及仅取消提醒。
- 支持一个待办一个一次性提醒、页内提醒、托盘气泡、10 分钟稍后提醒和应用启动后的单次补发。
- 支持通过已保存的 OpenAI 兼容配置，把一句自然语言解析为创建、修改、完成、删除或稍后提醒草稿。
- AI 确认卡显示完整年月日、时间、UTC 偏移和变更摘要；用户确认前不会写入任何待办或提醒。
- 模糊或过去时间进入澄清；同名待办要求选择唯一目标；AI 错误保留输入并支持重试、手动填写和清除内存内容。
- 新增 `AiPet.Todos` 模块与 16 项待办、提醒、AI 和 ViewModel 自动化测试。

## 数据与隐私

- 待办存储在当前账户的 `%APPDATA%\WindowsAiDesktopPet\todos.json`，使用 schema v1 和原子替换写入。
- AI 创建请求只发送本次输入、参考绝对时间和时区，不发送文件路径、搜索历史、快捷项或已有待办。
- 本版不持久化 AI 对话或模型原始响应；API Key 继续只保存在 Windows 凭据管理器。

## 提醒运行条件

- 应用运行时，页内提醒是主要反馈，托盘气泡是补充通道。
- 应用退出或电脑休眠期间不会由系统后台任务准点唤起；下次启动后，仍待投递的一次性提醒补发一次。
- Windows 专注助手或系统策略可能隐藏托盘气泡；失败不会被记录为成功，也不会对同一提醒自动重复轰炸。
