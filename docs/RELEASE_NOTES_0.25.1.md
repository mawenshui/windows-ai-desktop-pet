# Windows AI 桌面宠物 0.25.1

日期：2026-09-18。0.25.1 是兼容性修复版本，不增加预览通道，也不改变用户数据 schema。

## 修复

- 更新检查与安装器下载显式共用 Windows 用户代理及标准 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` 环境代理；使用国外系统代理时走官方 GitHub，官方不畅时继续尝试内置匿名加速线路。
- GitHub latest API 返回匿名 404 时，设置页改为说明更新源未公开或尚无正式 Release，不再误报“GitHub 官方和内置加速线路均未连接成功”。网络中断与元数据安全校验失败仍分别提示，且不会清除此前发现的版本。
- 深色主题现在覆盖整个工具窗口的主体、卡片、输入、文字、状态色、边框与阴影；切换回浅色会恢复完整浅色调色板，不再遗留深色边缘。
- 强调按钮、成功/错误提示和输入悬停边框使用主题语义色，保证深浅主题下的状态辨识与文字对比。
- 修复待办快捷时间、跨日复盘与专注日汇总受运行机器时区影响的问题；UTC GitHub runner 与用户本地时区使用同一墙钟语义。

## 更新前提

自动更新坚持匿名读取固定 GitHub Release，不要求用户填写 Token。对应 GitHub 仓库必须为 Public 且存在普通正式 Release；Private 仓库对匿名客户端返回 404，任何本地代理或加速线路都不能绕过 GitHub 权限。仓库可见性由维护者明确决定，应用不会自动修改。

当前仓库已由维护者设为 Public。2026-09-18 的匿名在线验收确认 GitHub 官方与内置加速元数据线路可访问，且项目更新客户端可下载当前正式安装器并通过 SHA-256 校验。

## 验证状态

测试、打包和可选诊断结果见 [0.25.1 验证报告](release/0.25.1-test-report.md)。正式发布只要求 automated 与 package-smoke 通过；UI、性能、签名和物理硬件矩阵不再阻断发布。项目不创建 Preview、Alpha、Beta、RC 或 Pre-release。
