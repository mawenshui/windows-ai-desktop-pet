# Windows AI Desktop Pet 0.7.0 本地交付说明

> 状态：源码与本地构建候选。尚未创建 Git 标签或 GitHub Release，不代表已公开发布。

## 主页体验

- 页签切换与常驻、置顶、关闭控件位于同一行，主页移除冗余标题和说明。
- 搜索范围与输入框保持单行完整显示；搜索结果位于快捷入口之前。
- 已有查询时切换范围立即重新搜索，并通过取消令牌与请求代次阻止旧结果覆盖新结果。

## 快捷入口

- 应用、文件、目录分别显示 Windows Shell 对应图标，读取失败时回退应用内置图形。
- 支持文件、应用、目录和拖放添加；入口数量较多时使用水平滚动。
- 支持编辑名称、描述和本地图标，支持上下排序、重新定位和移除引用。
- 重复目标先询问用户是否继续，选择取消时不生成记录；快捷卡片可直接读取用户描述。
- 无效图标、空名称和目标失效均保留当前内容并提供可恢复提示。

## 验证

- `pwsh -NoProfile -File scripts/validate-project.ps1`：通过。
- `pwsh -NoProfile -File scripts/test.ps1 -CI`：119 项通过，0 失败，0 跳过。
- WPF 主页快照：`440×536` 实际渲染中范围文字、搜索框、顶栏、结果区与快捷入口无明显截断。
- 便携包：从最终 ZIP 解压后 `--smoke` 通过，覆盖资源、搜索、快捷入口、AI 预设、凭据安全存储、自启读取和离线帮助。
- 安装包：静默安装到隔离测试目录、启动 `--smoke`、静默卸载均返回 0；诊断日志位于用户数据目录，安装目录无运行时残留。
- 发布资产：便携 ZIP、Inno Setup 安装 EXE 与 `SHA256SUMS.txt` 已在本地生成并核对。
