Windows AI Desktop Pet 用户手册

适用版本：0.25.2 正式版；修订：2026-09-18。项目不提供预览版；本版本已发布为普通 GitHub Release 和 Latest。

1. 安装与退出

完整解压 windows-ai-desktop-pet-v0.25.2-portable.zip 后运行 WindowsAiDesktopPet.exe，保留 assets、docs 和旁边的运行时文件；或双击 windows-ai-desktop-pet-v0.25.2-setup.exe。安装器默认使用当前账户的 %LOCALAPPDATA%/Programs/WindowsAiDesktopPet，两类包均自带运行时。

关闭工具窗只是收起。托盘“退出”才结束应用，自启默认关闭，可在设置或托盘启用。便携目录移动后重新检查自启。便携版和安装版默认共用当前 Windows 账户数据。

交互卸载会询问是否清理个人数据，默认“否”。选择“是”删除已识别的设置、待办、提醒队列、每日复盘、专注记录、快捷引用、索引、日志、维护快照、设置中记录的本应用 AI 凭据和旧版本遗留的更新凭据；目标原文件及未知文件保留。先退出桌宠；清理失败会停止卸载并提示。丢失设置中未记录的旧凭据需自行在 Windows 凭据管理器处理。静默卸载始终保留个人数据。卸载移除指向本次安装位置的自启项；指向其他便携位置的配置不受影响。

2. 桌宠与工具窗

单击桌宠打开或收起工具窗，双击播放动作，拖动移动位置。工具窗跟随宠物定位并记忆位置。隐藏后通过托盘恢复。四页为主页、待办、维护、设置；常驻与置顶独立保存。Esc、关闭按钮和显式收起始终可用。

选项直接显示在按钮组或列表，Tab 聚焦、方向键/Home/End 选择，Ctrl+Tab / Ctrl+Shift+Tab 循环切页。Alt+1～Alt+4 可直接进入四页；Ctrl+L 返回搜索，Ctrl+N 打开待办编辑器，待办页 Ctrl+F 通常聚焦清单查找，在提醒区域内则聚焦提醒查找，编辑时 Ctrl+Enter 保存，F1 打开包内离线手册。AI 有未保存修改时，鼠标、键盘和所有定向入口都先确认；取消会保留原编辑页面。

设置顶部有外观、快捷键、更新、搜索、AI 五项目录。四个内置 RGS 角色以真实正面首帧卡片展示中文名、选中状态和 CC0-1.0 许可，可打开包内本地许可；角色卡不联网也不播放额外预览动画。切换保存成功后才应用，资源异常会回退到可显示角色。系统/浅色/深色/高对比度主题会同步更新整个工具窗的背景、卡片、输入、文字、状态色、边框与阴影，切回浅色不会保留深色边缘。

“低打扰”提供两个默认关闭且需显式保存的开关：其他应用同屏全屏时隐藏桌宠、专注时允许桌宠点击穿透。普通最大化和本应用窗口不触发全屏隐藏；应用只恢复自己隐藏的桌宠。点击穿透生效时可从托盘恢复交互，打开设置也会恢复当前会话交互。

默认按 Ctrl+Alt+Space 可从其他普通窗口显示桌宠、打开主页并聚焦搜索；Ctrl+Alt+T 打开待办页、新建一条待办并聚焦标题。设置 → 快捷唤出可停用或修改两个组合键，格式为修饰键加普通键，例如 Ctrl+Shift+F12。两个组合不能相同；若任一组合被系统或其他程序占用，本应用会停用两者并显示原因，避免只生效一半。修改后按钮标记“有修改”，成功保存并应用后显示“已保存”；格式或写入失败时输入仍保留。托盘“立即搜索”“快速记待办”始终可用。修改快捷键不会绕过 AI 未保存编辑确认。

3. 搜索

首次选择桌面、文档、下载等候选并确认授权，或稍后到设置添加文件夹。确认前不枚举，默认不扫描全盘；文件正文搜索默认关闭。应用入口来自开始菜单及 App Paths，不保证包含每一个应用。

主页按范围、类别筛选，默认输入后约 300 ms 查询。设置中选择“名称”或“相对路径”，相对路径从授权根开始。可独立启用 * / ? 通配符和 re: 正则；错误及超时会提示修改。结果显示匹配原因，默认精确、前缀、包含优先，每页 50 条，“继续加载”获取后续结果。索引变化时重新查询，避免拼接不同数据批次。

输入搜索词后，搜索框右侧显示“×”。点击或在搜索框按 Esc 会清空搜索和旧选择，保留当前类别/范围并把焦点留在搜索框。无结果时可“重置搜索条件”一次恢复空查询、全部类别和全部范围，或进入搜索范围管理。结果标题显示已显示数量，选中摘要显示序号/总数。查询为空时再按 Esc 才收起工具窗；搜索框按 Down 进入首条结果，结果首条按 Up 返回搜索框。

需要按正文查找时，在设置 → 搜索范围开启“读取授权范围内的受控文本正文”。应用只读取已授权目录内不超过 128 KiB 的 .txt 和 .md，支持严格 UTF-8 及带 BOM 的 UTF-16；每个范围最多 1,000 个正文文件、16 MiB。隐藏、系统、链接、二进制、非法编码、超限和不可读文件会跳过，名称索引仍可用。普通文字会补充正文匹配；*/? 和 re: 只匹配所选名称或路径字段。

仅正文命中的结果显示“正文连续包含”和最多 120 字符的单行上下文，名称/路径命中优先。设置卡片显示索引数、跳过数和读取量，可重建，也可使用每个范围的取消操作。选择“停用并清除”会立即禁用查询并清空本机正文索引；移除范围只清除该范围的名称、正文和偏好，不删除原文件。正文、摘要和查询词不进入诊断、备份或 AI 请求。

可固定常用结果。启用“最近使用排序”前会说明记录已打开结果的路径和时间，数据只在本机；可关闭或清除记录，清除不取消固定。常规重新索引保留偏好；缓存清理或撤销范围会删除对应偏好，需要重新固定。

单击结果或使用方向键选中后，列表下方出现操作区：

  • “打开”使用 Windows 默认关联程序；双击结果或选中后按 Enter 仍可直接打开。
  • “定位”在文件资源管理器中选中原文件或文件夹；驱动器根目录会直接打开。
  • “复制路径”把完整路径写入剪贴板，不保存到设置、诊断或 AI 请求。
  • “加入快捷入口”复用现有快捷入口的默认名称、图标和重复检查；成功加入后显示“已在快捷入口”并禁用，快捷入口被移除或重新定位后会实时恢复可用状态。

打开、定位和加入前会重新检查目标。目标已被移动或删除时，这三项不可用，复制路径仍可帮助排查；应用不会自动删除原索引项。手动重查或索引刷新后，若相同范围和路径仍在首屏，当前选择会恢复；修改关键词、类别、范围、查询字段、通配符、正则或正文模式会清除旧选择。

范围可取消重建、重试、移除。重启恢复监听，目录改名/删除处理子树；事件溢出重建。取消重建保留上一份成功结果；权限、目录变化或监听失败时可手动重新索引。

4. 快捷入口

主页“添加入口”“文件夹”及批量拖入保留原操作。六列紧凑网格提供名称、图标和静止可见的“⋯”编辑菜单。自定义图标复制到本机缓存；失效项显示警示图形及说明，不只依赖颜色，并可重新定位。

“管理”打开独立管理窗：按全部、固定、未分组、失效或自定义组筛选，顶部显示当前结果数和选择数。Ctrl / Shift 多选，填写组名后“移入分组”，空名称时按钮显示“移出分组”；可以批量固定。重新定位和排序只允许单选，到达列表或固定区边界时上移/下移自动禁用。单项仍可用 Alt+↑/↓ 或拖动排序。

“检查失效”可取消，扫描期间禁用重复扫描与数据修改，只开放“取消检查”；选择一个失效入口重新定位。“预览批量移除”先列出名称和路径，确认只删快捷引用；Delete 键也只打开同一预览。本次运行可撤销最近一批移除，重启不保留撤销。清理缓存保留被入口或当前撤销记录引用的图标。

5. 待办、重复与多次提醒

待办页首先显示清单标题、新建按钮、六类带计数筛选、只匹配标题/备注的本地查找、时间最近/新建在前/标题排序和手动列表。清空查找保留筛选与排序；待处理空态可新建，其他筛选空态返回待处理，查询无匹配时只清空查找。“一句话安排（AI 可选）”与“今日安排”默认折叠，草稿、澄清或错误时自动展开。

待办页顶部可在“清单 / 复盘”间切换，默认进入清单，不增加新的主页面。复盘显示日期导航，以及从本地待办计算的已完成、待处理、已安排数量和相关事项只读标题；不会从复盘反向修改待办。

“专注陪伴”可使用 15、25、50 分钟快捷值，或输入 5～180 分钟；可关联当前选中的未完成普通待办，也可无关联开始。一个时刻只允许一个运行或暂停会话，可暂停、继续或经确认提前结束。任何结果都不会自动完成关联待办；只有关联项仍待处理时才提供明确完成按钮。

专注运行和暂停期间，桌宠停止自主漫游、随机气泡和鼠标朝向，正式提醒仍可显示；结束后恢复原设置。应用重启、休眠和系统时间变化后会校准本机记录，显著回拨时自动暂停。复盘与 Markdown 按日期显示完成次数、总时长和提前结束次数。

复盘记录最多 4,000 字，停止输入约 500 ms 后自动保存到当前账户的 journal.json；Ctrl+S 可立即重试。跨日、系统时间变化或休眠恢复会冻结前一活动日快照。历史默认只读，明确编辑只改文字；删除经页内确认且只删除当前日期复盘。按 Esc 先退出历史编辑或回到清单，再按一次才收起工具窗。

“导出 Markdown”打开 Windows 保存对话框，默认名 YYYY-MM-DD.md。只有确认后才写入 UTF-8 无 BOM、LF 文件；覆盖由系统确认。应用不后台写入 Documents，不隐式授权搜索目录，导出失败不删除应用内正文。

列表使用原生单选：方向键/Home/End 移动，Enter/F2 编辑，Ctrl+Enter 完成或恢复，Delete 可撤销删除，双击也可编辑。选中后统一操作带按事项状态提供完成/恢复、编辑、稍后、跳过、取消规则/提醒和删除；卡片用文字标明已逾期、今天、未来、未安排和已完成。

编辑器可快速设置今天/明天 18:00 截止、30 分钟后/明天 09:00 提醒或清除对应时间；动作只改草稿。标题/备注显示 200/4000 长度计数，实时提示空标题、时间格式及提醒必填等问题。字段变化清理旧提交错误；取消或 Esc 先显示“继续编辑/放弃修改”，只有明确放弃才关闭。

手动新建、修改、完成、恢复、稍后、取消提醒和删除都共用最近一次撤销。删除立即执行并可撤销，不再弹 Yes/No 确认。撤销不跨重启；目标后续变更时会拒绝用旧快照覆盖。

展开“今日安排”后可勾选 1～12 条待处理事项，或使用“选择前 12 条/清除选择”，再选择 AI 或不访问网络的本地安排。AI 只接收本次勾选项的正文与时间；未勾选事项只提供匿名占用时间。任何选择变化都会清除旧草稿。

安排先显示内存草稿，包括每项开始/结束、简短理由和已避让的既有时间段数量。取消单项勾选可排除该项；点击“确认应用所选”后才整批保存，列表显示计划时间块，截止时间同步为块结束。草稿生成后若任一事项已修改，整批不会写入，需重新生成。最近一批可整体撤销；若安排应用后事项又被修改，旧撤销不会覆盖新内容。退出后不保留撤销历史。手动或单项 AI 修改截止时间会清除旧计划开始时间。

展开“重复与额外提醒”：选择一次性、每天、每周、工作日或自选星期；间隔 1～365，工作日/自选星期的间隔按周计算，周从星期一开始。首次时间是明确指定的例外起点，之后才按所选日历规则推进。结束日期包含所选时区当天 23:59。

时间按编辑器所选时区解释，重复始终保持该时区的当地钟点。Windows 时区改变不会把旧规则改到新地区；静默时段则跟随当前 Windows 时区。夏令时不存在的钟点移到首个有效分钟，重复钟点选较晚的一次。旧规则没有时区 ID 时保留原固定偏移，重新编辑整条规则可选择时区。

每行可追加一个 yyyy-MM-dd HH:mm 时间，最多 32 个，去重并按最早有效时刻调度。预览展示前四个时间。编辑时勾选“仅调整此次时间”保留标题、备注、通道及原规则锚点；不勾选则保存整条规则。跳过此次推进下次，取消整个规则清除后续所有时间；完成普通待办也取消其未来提醒。

停机或休眠错过多次时，恢复后汇总一次，跳到未来的有效时间，不逐条追赶。普通待办提醒不自动完成；独立提醒在最后一次通知提交后完成，仍可从提醒中心安排稍后提醒。退出、关机和休眠期间没有进程外准点唤醒。

6. 提醒中心

到期先持久化排队，宿主每 5 秒处理一次，将同时到期事项合并，两次提交至少间隔 30 秒。中心按标题在本机当前提醒记录中查找，并提供“待处理/历史/全部”计数和“处理优先/最近记录”排序；清空查找保留筛选与排序。无记录、筛选为空和查找无匹配分别提供测试通道、切换分段或清空查找的恢复动作。

提醒列表为原生单选，方向键/Home/End 移动；选中后统一操作带只对当前记录提供详情、完成或 5/10/30/60 分钟稍后。Enter/F2 打开详情，Ctrl+Enter 完成，Ctrl+Shift+Enter 按当前时长稍后；双击也可打开详情。刷新只恢复仍在当前结果中的同一通知，不会自动跳到另一条。清除已处理/测试历史不会删除待办或未处理业务提醒。

“静默与历史”使用启用、开始、结束三个草稿字段，时间严格为 HH:mm，启用时起止不能相同，支持跨午夜。夜间 22:00～08:00、午休 12:00～13:00 和关闭静默只修改草稿，点击保存后才写入；错误或保存失败会保留输入。静默期间排队，结束后合并提交。测试通道使用固定示例，不读取待办正文。隐藏桌宠时不强行显示宠物；托盘和中心保留提醒。

“排队中”表示已保存待提交，“已提交 · 展示未确认”只表示宿主已接受请求；Windows 通知设置、专注助手可能抑制显示。没有已读检测或“保证已看到”的状态。当前最多保存 2,000 条，满额会拒绝新入队并显示失败，整理已处理历史后重新安排。

7. AI 配置与草稿

设置 → AI 接入：模板新建，填写名称、供应商、地址、模型和 Key。“测试连接”验证端点响应、JSON 模型列表和所选模型存在性；HTTP 200 但格式错误或没有模型仍不通过。可取消；鉴权、权限、限流、端点、模型、响应、网络和超时分别提示。

“验证草稿生成”需主动确认可能消耗服务额度，发送固定测试文本并验证最小结构化草稿，测试结果不写入待办。列表验证通过不等于生成权限通过；生成验证也不承诺服务后续稳定。编辑字段会使旧测试失效，只有当前字段成功验证才可保存。Key 仅存 Windows 账户安全存储，自动化测试使用 fake HTTP。

展开“AI 配置迁移”后可使用完整迁移：

  1. 选择“导出完整配置”，指定 .aipet-ai-config 文件，输入至少 10 个字符的迁移口令并再次确认。
  2. 完整包包含全部已保存配置、当前配置、连接状态、自定义 Provider 预设和 API Key。内容经口令加密，文件中不保存原设备的 Windows 凭据目标名。
  3. 在目标设备选择“导入完整配置”，输入相同口令。核对来源版本、导出时间、配置数、含 Key 数、自定义 Provider 数和即将启用的配置。
  4. 确认后会替换目标设备当前的全部 AI 配置和自定义 Provider 预设；其他设置不变。Key 写入目标 Windows 账户凭据库，原当前配置会立即加载，可以直接使用。

口令不会保存，遗失后无法恢复。配置文件包含可解密的 Key，应与口令分开并通过可信渠道保存；不再需要时安全删除。错误口令、损坏、篡改、无效端点或中途凭据写入失败都会停止整个导入，原配置保持不变。完整包最大 4 MB、最多 100 组配置和 32 个自定义 Provider。

“兼容迁移（不含 Key）”继续导出名称、供应商、地址和模型；导入先预览，重名可跳过或重命名。新配置需补充 Key 和验证，导入不替换活动配置。无 Key JSON 最大 1 MB。单独导入自定义预设仍不能覆盖内置 ID；模板地址可编辑。

待办页展开“一句话安排（AI 可选）”后输入文字生成草稿，发送的只有本次文字、当前时间和时区提示，不发送已有列表、搜索索引或文件路径。可表达创建、修改、完成、删除、稍后、重复和多个时间。核对时间、规则和目标，重名可重新选择；确认后才写入。取消、转手动、单次撤销保留，撤销和对话不会跨重启保存。

8. 应用更新

每次正常启动会在后台检查一次指定 GitHub 公开仓库的最新稳定 Release；无更新、断网或 GitHub 暂时不可用都不会阻止桌宠启动，也不会自动下载安装。在设置 → 应用更新可“立即检查”，或开启运行期间周期检查并填写 1～168 小时。周期或间隔变化后保存按钮标记“有修改”，成功写入后显示“已保存”；输入不合法或写入失败时仍保留未保存状态。检查和下载共用 Windows 用户代理设置，也识别标准 HTTP_PROXY、HTTPS_PROXY 与 NO_PROXY 环境配置。

更新线路已经内置，无需填写代理地址、加速模板或 GitHub Token。应用会优先检查 GitHub 官方元数据，连接不畅时自动切换智能加速；下载时也会逐条尝试内置线路并最终回退官方地址。若 GitHub 官方返回匿名 404，则会明确提示“更新源未公开或尚无正式 Release”，不会再误报为本机代理或所有线路故障；匿名自动更新要求发布仓库为 Public。

发现新版本后选择“下载并准备安装”。后续检查如果临时断网，已发现版本和下载入口会保留；只有明确确认当前已是最新版本时才清除。应用只接受固定仓库、精确版本标签和文件名匹配的安装器，并读取同一 Release 的 SHA256SUMS.txt；Release 提供 digest 时还会交叉核对。校验失败会删除临时文件并保留当前版本。校验通过后仍会询问，确认后才启动安装器并退出。便携版用户也会下载安装器；如希望继续使用便携版，可取消并手动下载便携包。

9. 维护与隐私

备份先选模块并查看大小。可包括设置、位置、待办与提醒队列、每日复盘、专注记录、快捷入口与图标、AI 预设和实际 LocalAppData 日志。索引是可重建数据，不复制正在使用的 SQLite；普通维护备份始终不含 Key，与设置页中用户主动创建的加密完整 AI 配置包不同。备份包含个人正文和路径，请妥善保存。

每日自动备份默认开启，应用正常启动时检查，距最近一次不足 24 小时则不重复创建。默认保留 7 份，可在维护页设置为 1～30 份；开关或保留份数改变后按钮显示“保存设置（有修改）”，成功后显示“已保存”。也可“立即创建”或打开备份文件夹。自动包位于 %APPDATA%/WindowsAiDesktopPet/automatic-backups，包含设置、窗口位置、待办/提醒、每日复盘、专注记录、快捷入口/图标和 Provider 预设，不含 API Key、搜索索引或诊断日志。只有新包校验并写入成功后才清理超出上限的旧包；失败时原数据和旧备份保留。

恢复先验证清单、哈希、schema、容量及路径，再显示模块当前/传入大小。快捷项与图标、待办与提醒队列成组处理。确认后退出应用；下次启动在后台服务建立前执行切换，保留恢复前快照，失败或中断可回滚。旧备份没有队列时清除陈旧队列；含排队状态却缺队列的备份会拒绝。跨设备文件路径仍需重新定位，凭据不随备份迁移。

恢复上限 512 MB、单项 64 MB、10,000 个数据文件，拒绝越界/链接、未知模块、无效 JSON 和凭据字段。不要手工修改备份 ZIP。恢复回滚失败会停止启动保护原数据，保留 .maintenance 供排查。

“退出并重建缓存”会先显示独立确认，默认按钮是“保留并返回”。确认后清理无引用图标并立即退出；下次启动移除 index.db/WAL/SHM 和实际日志后重建。设置、待办、每日复盘、专注记录、快捷入口、正在引用的自定义图标和凭据不会删除，授权仍保留。损坏 JSON 不会被空列表保存覆盖；.previous、待办迁移前 .pre-v3.bak / .pre-v4.bak 和设置迁移前 .pre-v4.bak / .pre-v5.bak / .pre-v6.bak 可辅助恢复。

默认数据 %APPDATA%/WindowsAiDesktopPet，日志 %LOCALAPPDATA%/WindowsAiDesktopPet/logs。维护页底部播报最近操作状态；失败只说明数据是否保留、常见原因和下一步，不显示原始异常或完整路径。诊断 JSON 仅有版本、系统、模块计数和稳定状态码，不含 Key、完整路径、待办或 AI 原文。没有自动云上传。
