Windows AI Desktop Pet 用户手册

适用版本：0.16.0；修订：2026-09-09。候选版，真实桌面输入、签名和物理设备验收尚未全部通过。

1. 安装与退出

完整解压 windows-ai-desktop-pet-v0.16.0-portable.zip 后运行 WindowsAiDesktopPet.exe，保留 assets、docs 和旁边的运行时文件；或双击 windows-ai-desktop-pet-v0.16.0-setup.exe。安装器默认使用当前账户的 %LOCALAPPDATA%/Programs/WindowsAiDesktopPet，两类包均自带运行时。

关闭工具窗只是收起。托盘“退出”才结束应用，自启默认关闭，可在设置或托盘启用。便携目录移动后重新检查自启。便携版和安装版默认共用当前 Windows 账户数据。

交互卸载会询问是否清理个人数据，默认“否”。选择“是”删除已识别的设置、待办、提醒队列、快捷引用、索引、日志、维护快照、设置中记录的本应用 AI 凭据和固定的 GitHub 更新令牌；目标原文件及未知文件保留。先退出桌宠；清理失败会停止卸载并提示。丢失设置中未记录的旧凭据需自行在 Windows 凭据管理器处理。静默卸载始终保留个人数据。卸载移除指向本次安装位置的自启项；指向其他便携位置的配置不受影响。

2. 桌宠与工具窗

单击桌宠打开或收起工具窗，双击播放动作，拖动移动位置。工具窗跟随宠物定位并记忆位置。隐藏后通过托盘恢复。四页为主页、待办、维护、设置；常驻与置顶独立保存。Esc、关闭按钮和显式收起始终可用。

选项直接显示在按钮组或列表，Tab 聚焦、方向键/Home/End 选择，Ctrl+Tab / Ctrl+Shift+Tab 切页。AI 有未保存修改时，鼠标、键盘和定向提醒入口都先确认；取消会保留原编辑页面，未经验证不能强行保存。

设置支持四个内置 RGS 角色及系统/浅色/深色/高对比度主题；漫游、气泡动画、鼠标朝向跟随分别控制。系统关闭动画会限制动作。外部角色包目前没有用户导入入口。

默认按 Ctrl+Alt+Space 可从其他普通窗口显示桌宠、打开主页并聚焦搜索；Ctrl+Alt+T 打开待办页、新建一条待办并聚焦标题。设置 → 快捷唤出可停用或修改两个组合键，格式为修饰键加普通键，例如 Ctrl+Shift+F12。两个组合不能相同；若任一组合被系统或其他程序占用，本应用会停用两者并显示原因，避免只生效一半。托盘“立即搜索”“快速记待办”始终可用。修改快捷键不会绕过 AI 未保存编辑确认。

3. 搜索

首次选择桌面、文档、下载等候选并确认授权，或稍后到设置添加文件夹。确认前不枚举，默认不扫描全盘，不读取正文。应用入口来自开始菜单及 App Paths，不保证包含每一个应用。

主页按范围、类别筛选，默认输入后约 300 ms 查询。设置中选择“名称”或“相对路径”；相对路径从授权根开始，不是正文搜索。可独立启用 * / ? 通配符和 re: 正则；错误及超时会提示修改。结果显示匹配原因，默认精确、前缀、包含优先，每页 50 条，“继续加载”获取后续结果。索引变化时重新查询，避免拼接不同数据批次。

可固定常用结果。启用“最近使用排序”前会说明记录已打开结果的路径和时间，数据只在本机；可关闭或清除记录，清除不取消固定。常规重新索引保留偏好；缓存清理或撤销范围会删除对应偏好，需要重新固定。双击或选中后 Enter 通过系统打开。

范围可取消重建、重试、移除。重启恢复监听，目录改名/删除处理子树；事件溢出重建。取消重建保留上一份成功结果；撤销范围取消其任务并删除索引及偏好，不删除文件。权限、目录变化或监听失败时可手动重新索引。

4. 快捷入口

主页“添加入口”“文件夹”及批量拖入保留原操作。六列紧凑网格提供名称、图标和“⋯”编辑菜单。自定义图标复制到本机缓存；失效时可重新定位。

“管理”打开独立管理窗：按全部、固定、未分组、失效或自定义组筛选。Ctrl / Shift 多选，填写组名后“移入分组”，空名称表示取消分组；可以批量固定。单项用上移/下移、Alt+↑/↓ 或拖动排序，固定区与普通区分别排序。

“检查失效”可取消，原记录不变；选择一个失效入口重新定位。“预览批量移除”先列出名称和路径，确认只删快捷引用；本次运行可撤销最近一批移除，重启不保留撤销。清理缓存保留被入口或当前撤销记录引用的图标。

5. 待办、重复与多次提醒

普通待办填写标题、备注，可选截止和提醒；独立提醒需勾选提醒项并设置提醒时间。标题最多 200 字符，备注 4,000 字符。支持待处理、今天、已逾期、未安排、未来 7 天、已完成六类筛选，以及编辑、完成、恢复普通待办、删除和取消整个提醒规则。

“今日安排”列出待处理事项。勾选 1～12 条后，可选择“AI 安排今天”或“不访问网络的本地安排”。AI 只接收本次勾选项的 ID、标题、备注、截止时间和当前时间/时区；未勾选、已完成、搜索和提醒历史不会发送。本地安排按截止时间排序，从下一刻钟起为每项分配 30 分钟。

安排先显示内存草稿，包括每项开始/结束和简短理由。取消单项勾选可排除该项；点击“确认应用所选”后才整批保存，列表显示计划时间块，截止时间同步为块结束。草稿生成后若任一事项已修改，整批不会写入，需重新生成。最近一批可整体撤销；退出后不保留撤销历史。手动或单项 AI 修改截止时间会清除旧计划开始时间。

展开“重复与额外提醒”：选择一次性、每天、每周、工作日或自选星期；间隔 1～365，工作日/自选星期的间隔按周计算，周从星期一开始。首次时间是明确指定的例外起点，之后才按所选日历规则推进。结束日期包含所选时区当天 23:59。

时间按编辑器所选时区解释，重复始终保持该时区的当地钟点。Windows 时区改变不会把旧规则改到新地区；静默时段则跟随当前 Windows 时区。夏令时不存在的钟点移到首个有效分钟，重复钟点选较晚的一次。旧规则没有时区 ID 时保留原固定偏移，重新编辑整条规则可选择时区。

每行可追加一个 yyyy-MM-dd HH:mm 时间，最多 32 个，去重并按最早有效时刻调度。预览展示前四个时间。编辑时勾选“仅调整此次时间”保留标题、备注、通道及原规则锚点；不勾选则保存整条规则。跳过此次推进下次，取消整个规则清除后续所有时间；完成普通待办也取消其未来提醒。

停机或休眠错过多次时，恢复后汇总一次，跳到未来的有效时间，不逐条追赶。普通待办提醒不自动完成；独立提醒在最后一次通知提交后完成，仍可从提醒中心安排稍后提醒。退出、关机和休眠期间没有进程外准点唤醒。

6. 提醒中心

到期先持久化排队，宿主每 5 秒处理一次，将同时到期事项合并，两次提交至少间隔 30 秒。中心保留每个事项，可完成、详情或选择 5/10/30/60 分钟稍后；清除已处理历史不会删除待办或未处理提醒。

“静默与历史”可设置 HH:mm 开始/结束，支持跨午夜。静默期间排队，结束后合并提交。测试通道使用固定示例，不读取待办正文。隐藏桌宠时不强行显示宠物；托盘和中心保留提醒。

“排队中”表示已保存待提交，“已提交 · 展示未确认”只表示宿主已接受请求；Windows 通知设置、专注助手可能抑制显示。没有已读检测或“保证已看到”的状态。当前最多保存 2,000 条，满额会拒绝新入队并显示失败，整理已处理历史后重新安排。

7. AI 配置与草稿

设置 → AI 接入：模板新建，填写名称、供应商、地址、模型和 Key。“测试连接”验证端点响应、JSON 模型列表和所选模型存在性；HTTP 200 但格式错误或没有模型仍不通过。可取消；鉴权、权限、限流、端点、模型、响应、网络和超时分别提示。

“验证草稿生成”需主动确认可能消耗服务额度，发送固定测试文本并验证最小结构化草稿，测试结果不写入待办。列表验证通过不等于生成权限通过；生成验证也不承诺服务后续稳定。编辑字段会使旧测试失效，只有当前字段成功验证才可保存。Key 仅存 Windows 账户安全存储，自动化测试使用 fake HTTP。

展开“AI 配置迁移”可选择完整迁移。“导出完整配置”创建 .aipet-ai-config 文件，并要求输入至少 10 个字符的迁移口令和二次确认。完整包包含全部已保存配置、当前配置、连接状态、自定义 Provider 预设和 API Key，内容经口令加密，不保存原设备的 Windows 凭据目标名。

目标设备选择“导入完整配置”并输入相同口令。预览会显示来源版本、导出时间、配置数、含 Key 数、自定义 Provider 数和即将启用的配置，不显示 Key。确认后替换目标设备当前的全部 AI 配置和自定义 Provider 预设，其他设置不变；Key 写入目标 Windows 账户凭据库，原当前配置立即加载。

口令不会保存，遗失后无法恢复。配置文件包含可解密的 Key，应与口令分开并通过可信渠道保存，不再需要时安全删除。错误口令、篡改、无效端点或中途凭据写入失败会停止整个导入并保留原配置。完整包最大 4 MB、最多 100 组配置和 32 个自定义 Provider。

“兼容迁移（不含 Key）”继续导出名称、供应商、地址和模型；导入重名可跳过或重命名，新配置需补充 Key 和验证，且不替换活动配置。无 Key JSON 最大 1 MB。单独导入自定义预设仍不能覆盖内置 ID。

待办页输入一句话后生成草稿，发送的只有本次文字、当前时间和时区提示，不发送已有列表、搜索索引或文件路径。可表达创建、修改、完成、删除、稍后、重复和多个时间。核对时间、规则和目标，重名可重新选择；确认后才写入。取消、转手动、单次撤销保留，撤销和对话不会跨重启保存。

8. 应用更新

每次正常启动会在后台检查一次指定 GitHub 仓库的最新稳定 Release；无更新、断网或 GitHub 暂时不可用都不会阻止桌宠启动，也不会自动下载安装。在设置 → 应用更新可“立即检查”，或开启运行期间周期检查并填写 1～168 小时。系统代理自动生效。

国内网络如需加速，可展开“国内网络与自定义代理”，填写自己信任的 HTTPS 模板，并保留且只保留一个 {url} 占位符。应用先尝试该入口，再回退 GitHub 官方地址。第三方服务可看到请求的公开 Release 地址，请只使用可信服务。

当前仓库为私有时，可输入只具备仓库读取权限的 GitHub 访问令牌并选择“安全保存令牌”。令牌只进入当前 Windows 账户的凭据管理器，不写 settings、日志、诊断或备份；使用令牌时应用会忽略自定义加速模板，只连接 GitHub 官方 API 或系统代理。可随时“清除令牌”。

发现新版本后选择“下载并准备安装”。应用只接受与版本精确匹配的安装器，并读取同一 Release 的 SHA256SUMS.txt；校验失败会删除临时文件并保留当前版本。校验通过后仍会询问，确认后才启动安装器并退出。便携版用户也会下载安装器；如希望继续使用便携版，可取消并手动下载便携包。

9. 维护与隐私

备份先选模块并查看大小。可包括设置、位置、待办与提醒队列、快捷入口与图标、AI 预设和实际 LocalAppData 日志。索引是可重建数据，不复制正在使用的 SQLite；普通维护备份始终不含 Key，与设置页中用户主动创建的加密完整 AI 配置包不同。备份包含个人正文和路径，请妥善保存。

每日自动备份默认开启，应用正常启动时检查，距最近一次不足 24 小时则不重复创建。默认保留 7 份，可在维护页设置为 1～30 份；也可“立即创建”或打开备份文件夹。自动包位于 %APPDATA%/WindowsAiDesktopPet/automatic-backups，包含设置、窗口位置、待办/提醒、快捷入口/图标和 Provider 预设，不含 API Key、搜索索引或诊断日志。只有新包校验并写入成功后才清理超出上限的旧包；失败时原数据和旧备份保留。

恢复先验证清单、哈希、schema、容量及路径，再显示模块当前/传入大小。快捷项与图标、待办与提醒队列成组处理。确认后退出应用；下次启动在后台服务建立前执行切换，保留恢复前快照，失败或中断可回滚。旧备份没有队列时清除陈旧队列；含排队状态却缺队列的备份会拒绝。跨设备文件路径仍需重新定位，凭据不随备份迁移。

恢复上限 512 MB、单项 64 MB、10,000 个数据文件，拒绝越界/链接、未知模块、无效 JSON 和凭据字段。不要手工修改备份 ZIP。恢复回滚失败会停止启动保护原数据，保留 .maintenance 供排查。

缓存重建先清理无引用图标，然后退出；重启后移除 index.db/WAL/SHM 和实际日志。授权仍保留，重新索引后使用。损坏 JSON 不会被空列表保存覆盖；.previous、待办迁移前 .pre-v3.bak / .pre-v4.bak 和设置迁移前 .pre-v4.bak / .pre-v5.bak 可辅助恢复。

默认数据 %APPDATA%/WindowsAiDesktopPet，日志 %LOCALAPPDATA%/WindowsAiDesktopPet/logs。诊断 JSON 仅有版本、系统、模块计数和稳定状态码，不含 Key、完整路径、待办或 AI 原文。备份包含个人数据，诊断不是备份。没有自动云上传。

10. 常见问题

现象 处理
搜索为空或没有及时更新 检查授权、索引状态、名称/路径模式和类别；必要时重新索引
AI 连接成功但草稿失败 主动运行生成验证，核对模型权限/格式/额度；可转手动
今日安排无法生成 确认勾选 1～12 条；AI 失败可用本地安排，时间不足时减少选中项
没看到提醒 查提醒中心状态、静默时间、进程和 Windows 通知设置；已提交不等于已读
恢复后没有立即变化 恢复在下次启动执行，按提示退出再启动
快捷键没有生效 查看设置中的状态；修改被占用或重复的组合并保存，或用托盘等价入口
自动备份没有新增 24 小时内只建一次；查看维护页状态、目录权限和剩余空间，可用“立即创建”复核
数据损坏或维护失败 保留原文件、.previous、.pre-v3.bak、.pre-v4.bak、.pre-v5.bak 和 .maintenance，检查备份，不继续手改
帮助打不开 保留包内 docs/USER_MANUAL.html，检查 HTML 默认程序或修复安装
