Windows AI Desktop Pet

0.10.0 正式发布 · 待办与桌宠提醒相伴

156 项自动化、Windows 凭据往返、便携烟雾、隔离安装、安装后烟雾与卸载已经通过。二进制尚未签名；真实系统通知、Explorer 实际重启、休眠及多屏/缩放矩阵仍是待补验证项。

开始使用

  1. 启动后，RGS 桌宠会出现在桌面右下方，托盘区同时出现应用图标。
  2. 单击桌宠打开紧凑工具气泡；再次单击、按 Esc 或点击气泡外部可收起。
  3. 按住桌宠拖动可改变位置，已打开的工具窗口会即时跟随；近距跟随鼠标时只使用正面和左右侧面姿态，鼠标移远后回到正面。
  4. 长时间未操作时，宠物会低频说一句话、播放动作或短距离漫游；鼠标靠近、拖动或打开工具气泡会立即中断。

工具气泡右上角的图钉用于“常驻”（失焦不自动收起），叠层图标用于“保持置顶”。选中状态会保存到当前账户；关闭按钮、Esc 和再次点击宠物始终可以主动收起。

搜索与快捷入口

首次使用时主页显示搜索授权卡，预选“桌面、文档、下载”。确认前只展示路径、不枚举文件；可以取消任意候选或选择“稍后设置”。确认后才递归建立文件名索引，且不读取文件正文。

设置页会显示等待、准备中、可用、失败、已取消和路径失效状态，以及累计条目和上次成功时间。建立索引时可取消；失败或取消后上一份成功结果仍可查询，并可重试、重新索引或移除范围。

主页左侧可选择全部、应用或单个授权范围，结果区的类别下拉会立即过滤；已有关键词时切换搜索范围也会立即重新查询。默认按名称片段搜索；设置中可分别开启 */? 通配符与 re: 正则。双击结果打开目标。

快捷入口区域支持“添加入口”和“文件夹”选择器，也可以从资源管理器拖入文件或文件夹。入口默认使用目标的 Windows 图标：应用显示程序图标，文件按扩展名显示关联图标，目录显示文件夹图标。入口以六列正方形图标网格显示，较多时只使用纵向滚动；没有快捷入口时显示添加引导，添加任一入口后空状态背景和“文件夹＋”装饰图标会自动隐藏；悬停可查看名称、描述和完整路径，右键或入口上的“⋯”菜单可编辑名称、描述或图标、重新定位、排序和移除；首项的“上移”和末项的“下移”会自动禁用。自定义图标支持 ICO、PNG、JPG、JPEG，格式或内容不可读时会提示并回退目标图标。

切换桌宠

进入“设置 → 预设形象”，可在红帽勇者、方块伙伴、骷髅小队长和森林怪兽之间切换。素材来自 RGS_Dev，采用 CC0-1.0。

待办与独立提醒项

切换到“待办”页后，可按待处理、今天、未来 7 天和已完成筛选。普通待办支持标题、备注、截止、一次性提醒、完成、恢复、10 分钟后提醒、仅取消提醒和删除。

新建时勾选“这是提醒项”，设置必填提醒时间，并按需独立开启“桌宠漫游提醒”和“桌宠气泡提醒”。气泡与桌宠同窗，会随漫游和拖动移动；投递成功后提醒项自动进入“已完成”，失败时不会冒充完成。两个桌宠开关都关闭时仍保留托盘提醒；关闭 Windows 动画效果时只跳过漫游。

应用退出或电脑休眠期间不会后台唤起；下次启动时，尚未投递的一次性提醒补发一次。Windows 专注助手可能隐藏托盘气泡。

AI 一句话草稿

保存并测试通过 AI 配置后，可输入“明天下午 3 点提醒我提交周报”。AI 只生成结构化草稿；只有提醒时间而没有截止时间时，确认卡会显示“创建提醒项”，默认开启桌宠气泡。只有点击“确认执行”才写入；模糊、过去或冲突时间会要求补充，不会静默猜测。

解析失败、鉴权、限流、网络或超时时原句保持不变，可重试或转手动填写。创建请求只发送本次输入、参考时间和时区，不发送文件路径、搜索历史、快捷项或已有待办；本版不把 AI 对话写入磁盘。

AI 接入与隐私

AI 设置默认折叠。先在“已保存配置”中选择已有配置，或点击“新建”创建另一组命名配置；选择后会立即作为待办 AI 的当前配置。供应商下拉框显示供应商名称而非内部对象文本；选择内置供应商后，服务地址和模型会立即填入并仍可编辑。填写完整后先测试连接；连接正常后“保存配置”会立即变为可用。切换、切页或退出时若有未保存修改，会显示保存、放弃和取消。点击“删除当前配置”并二次确认后，会清除该配置、Windows 凭据、验证结果和内存 Key。API Key 不写入普通设置文件；连接测试不携带搜索词、文件路径或快捷项。

托盘菜单

宠物右键可选择“隐藏桌宠”。隐藏后双击托盘图标，或在托盘菜单选择“显示桌宠”即可恢复；每次打开托盘菜单都会重读桌宠、工具窗口和自启的真实状态，Explorer 重建任务栏后会尝试恢复托盘图标。

  • 显示桌宠 / 隐藏桌宠：切换桌宠；显示工具窗口 / 收起工具窗口：切换工具气泡。
  • 设置：直接打开设置页。
  • 开机自启：仅修改当前 Windows 账户的启动项，菜单打开时读取实际状态。
  • 帮助：打开本离线手册。
  • 退出：先处理未保存 AI 修改，取消搜索与 AI 后台任务，最多等待 5 秒后结束进程。

遇到问题

如果宠物不显示，请确认安装目录包含 assets/pets/RGS_8Directional/pet.json 与 frames。搜索无结果时，检查搜索范围是否已添加并完成索引。早期预览版误建的配置目录会在首次保存时改名保留并自动修复。

完整需求、隐私边界和开发说明见仓库中的 PRD、PROJECT_SPEC 与 USER_MANUAL.md。
