开始使用

  1. 启动后，RGS 桌宠会出现在桌面右下方，托盘区同时出现应用图标。
  2. 单击桌宠打开紧凑工具气泡；再次单击、按 Esc 或点击气泡外部可收起。
  3. 按住桌宠拖动可改变位置，已打开的工具窗口会即时跟随；近距跟随鼠标时只使用正面和左右侧面姿态，鼠标移远后回到正面。
  4. 长时间未操作时，宠物会低频说一句话、播放动作或短距离漫游；鼠标靠近、拖动或打开工具气泡会立即中断。

工具气泡右上角的图钉用于“常驻”（失焦不自动收起），叠层图标用于“保持置顶”。选中状态会保存到当前账户；关闭按钮、Esc 和再次点击宠物始终可以主动收起。

搜索与快捷入口

首次使用请进入“设置 → 搜索范围”，点击“添加文件夹”。只有明确选择的目录会递归建立文件名索引，不读取文件正文。

主页左侧可选择全部、应用或单个授权范围，结果区的类别下拉会立即过滤；已有关键词时切换搜索范围也会立即重新查询。默认按名称片段搜索；设置中可分别开启 */? 通配符与 re: 正则。双击结果打开目标。

快捷入口区域支持“添加入口”和“文件夹”选择器，也可以从资源管理器拖入文件或文件夹。入口默认使用目标的 Windows 图标：应用显示程序图标，文件按扩展名显示关联图标，目录显示文件夹图标。入口以六列正方形图标网格显示，较多时只使用纵向滚动；悬停可查看名称、描述和完整路径，右键或入口上的“⋯”菜单可编辑名称、描述或图标、重新定位、排序和移除；首项的“上移”和末项的“下移”会自动禁用。自定义图标支持 ICO、PNG、JPG、JPEG，格式或内容不可读时会提示并回退目标图标。

切换桌宠

进入“设置 → 预设形象”，可在红帽勇者、方块伙伴、骷髅小队长和森林怪兽之间切换。素材来自 RGS_Dev，采用 CC0-1.0。

AI 接入与隐私

AI 设置默认折叠。选择内置供应商后，服务地址和模型会立即填入并仍可编辑。填写完整后先测试连接；只有当前配置通过测试，“保存配置”才可用。修改任一字段会使通过状态失效，失败时输入保持不变且不会覆盖已保存配置。API Key 使用当前 Windows 账户的凭据存储，不写入普通设置文件。连接测试不携带搜索词、文件路径或快捷项。

托盘菜单

宠物右键可选择“隐藏桌宠”。隐藏后双击托盘图标，或在托盘菜单选择“显示桌宠”即可恢复；工具窗口有独立的显示/收起菜单。

  • 显示 / 隐藏：切换工具气泡。
  • 设置：直接打开设置页。
  • 开机自启：仅修改当前 Windows 账户的启动项。
  • 帮助：打开本离线手册。
  • 退出：结束桌宠与后台进程。

遇到问题

如果宠物不显示，请确认安装目录包含 assets/pets/RGS_8Directional/pet.json 与 frames。搜索无结果时，检查搜索范围是否已添加并完成索引。早期预览版误建的配置目录会在首次保存时改名保留并自动修复。

完整需求、隐私边界和开发说明见仓库中的 PRD、PROJECT_SPEC 与 USER_MANUAL.md。
