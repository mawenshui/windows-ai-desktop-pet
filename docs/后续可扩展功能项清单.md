# Windows AI Desktop Pet 后续可扩展功能项清单

| 属性 | 内容 |
| :--- | :--- |
| 基线版本 | `0.10.0` |
| 清单日期 | 2026-09-03 |
| 来源 | `docs/已有功能优化.md`、PRD、技术设计与测试计划中的未完成项 |
| 性质 | 候选 Roadmap；不代表已经承诺版本、排期或上线 |

## 1. 排期原则

1. 先偿还系统验证、数据迁移和提醒正确性债务，再扩展用户可见能力。
2. 每个功能进入开发前关联现有 `OPT-*`/PRD 编号；若改变数据、权限、隐私或安装行为，先补 RFC。
3. AI 写入、文件内容读取、遥测和在线服务继续遵循最小化、明确告知及用户确认原则。
4. 新角色、字体、图标和模型必须有可追溯且允许再分发的许可证，不引入商业 IP 素材。

## 2. R0：发布后稳定性与验证债务

| 编号 | 功能项 | 优先级 | 依赖 | 最小验收口径 |
| :--- | :--- | :--- | :--- | :--- |
| EXT-QA-001 | Windows 系统交互 E2E runner | P0 | `OPT-QA-002` | 独立执行宠物、工具窗、托盘、自启、帮助、退出主路径；通过/失败/跳过分别报告 |
| EXT-TRAY-001 | Explorer 重启与托盘恢复自动化 | P0 | `OPT-TRAY-001` | 重启 Explorer 后图标自动恢复、菜单状态准确，后台任务退出不超过 5 秒 |
| EXT-COMPAT-001 | 多屏、负坐标与 100%～200% 缩放矩阵 | P0 | E2E runner | 宠物和工具窗始终保留可操作区域，显示器断开/重连后自动回到有效工作区 |
| EXT-REM-001 | 休眠、时区和系统时间变化恢复 | P0 | `OPT-REM-001` | 恢复后按冻结规则补发或标记错过，同一提醒最多投递一次 |
| EXT-REL-001 | 代码签名与发布证明 | P1 | 签名证书、CI secrets | EXE 与安装器签名可验证，Release 保留构建来源、哈希和验证报告 |

## 7. 需单独 RFC 的探索项

| 编号 | 候选方向 | 进入条件 |
| :--- | :--- | :--- |
| RFC-SRCH-001 | 文档正文、OCR 或语义搜索 | 完成隐私、性能、文件格式、索引清理和本地/云端处理边界评审 |
| RFC-PET-001 | Styloo Chibi 等可再分发 3D 角色 | 许可证复核、透明 WPF/3D 兼容性、资源预算和 2D 回退方案通过 |
| RFC-NAV-001 | 第二扩展页业务定义 | 完成用户问题、价值指标、数据边界和退出/回滚方案，不预设为聊天、养成或商城 |
| RFC-AI-001 | 用户扩展 AI Provider 预设 | schema、签名/来源、端点安全、升级兼容和错误隔离方案通过 |
| RFC-HELP-001 | 在线帮助兜底 | 官网归属、隐私告知、离线优先和链接失效策略通过 |

## 8. 建议版本组合

- `0.10.x`：只处理兼容性、安全和发布后缺陷，不新增大能力。
- `0.11.0`：提醒恢复、数据迁移、诊断导出和独立系统 E2E。
- `0.12.0`：增量索引、相关性排序、分页及快捷项治理。
- `0.13.0`：页面/ViewModel 拆分、键盘、读屏、主题和动态效果偏好。
- `0.14.0`：Provider 能力元数据、待办统一撤销、可解释排序和原生通知。
- P2/RFC 项不绑定版本，评审通过后再进入 PRD 与测试计划。
