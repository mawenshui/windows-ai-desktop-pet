本清单不复述当前版本已经具备的功能。现有能力、验证结果与发布边界分别以 `docs/RELEASE_NOTES_0.12.1.md`、`docs/TEST_PLAN.md` 和 `docs/PROJECT_SPEC.md` 为准。

## 1. 规划原则

1. 先关闭真实 Windows 环境、可访问性、性能和发布可信度缺口，再增加新的常驻能力。
2. 新功能必须说明用户问题、数据边界、退出方式和可量化验收结果；不能只以“增加入口”作为完成标准。
3. 涉及凭据、文件内容、跨设备数据、系统级快捷键、脚本执行或在线服务时，必须先完成威胁建模和 RFC。
4. 常驻桌面进程优先选择低资源、可暂停、可撤销的设计；后台能力必须允许用户关闭。
5. 新视觉资源必须具有可再分发许可和 SPDX 标识，不使用商业角色 IP 或权利不清晰的素材。

| 编号 | 候选项 | 优先级 | 进入条件 | 最小验收口径 |

| NEXT-PAGE-001 | 可配置工具页模块 | P2 | 页面生命周期、导航恢复和资源配额协议冻结 | 扩展页可以注册卡片或独立页面；崩溃模块被隔离并可禁用；布局升级失败时回退到默认导航 |
| NEXT-PET-001 | 2D 行为包与动作编排 | P2 | 资产许可校验、动作 schema 和性能预算确定 | 新角色或动作包无需改应用代码即可载入；非法清单拒绝加载；每个包可单独禁用并保留内置角色回退 |
| NEXT-IMPORT-001 | 可移植扩展包格式 | P2 | NEXT-EXT-001 与数据迁移策略完成 | 导入前展示来源、许可、权限和将写入的文件；校验失败不落盘；导出不包含凭据、用户绝对路径或私人内容 |

## 6. R4：可选跨设备能力

该阶段默认不启用，任何网络传输都需要独立 RFC、隐私说明和显式开关。

| 编号 | 候选项 | 优先级 | 进入条件 | 最小验收口径 |
| :--- | :--- | :--- | :--- | :--- |
| NEXT-SYNC-001 | 端到端加密设备同步 | P2 | 账户体系、密钥恢复、冲突策略和服务成本评审 | 服务端无法读取同步正文；支持设备移除、密钥轮换、离线编辑和冲突预览；关闭同步后本地功能完整可用 |
| NEXT-SYNC-002 | 局域网设备接力 | P2 | 设备发现、配对和网络边界威胁模型完成 | 必须通过一次性配对确认；默认不广播私人内容；传输加密且可随时撤销已信任设备 |
| NEXT-BACKUP-001 | 用户自选目录的定时加密备份 | P2 | 加密容器格式、凭据托管和失败恢复方案通过 | 用户明确选择目录和频率；备份原子写入并可验证恢复；空间不足或目标离线时不破坏上一份备份 |
| NEXT-METRIC-001 | 明确同意的匿名质量反馈 | P2 | 隐私政策、事件字典和关闭/删除机制通过法律与产品评审 | 默认关闭；启用前展示字段；不收集查询词、路径、事项内容、AI 原文或设备唯一标识；用户可查看并清除待上传事件 |
