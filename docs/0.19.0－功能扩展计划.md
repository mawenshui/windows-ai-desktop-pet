# 0.19.0－功能扩展计划

> 日期：2026-09-13；状态：实现完成，候选验证中。完整设计、决策依据和验收细节见[0.19.0－交互与功能完善设计](0.19.0－交互与功能完善设计.md)。

## 本版目标

在不改变数据格式、隐私边界、依赖或四页结构的前提下，逐一完善已有工具窗的布局、操作命中区、键盘连续性、焦点恢复、渐进披露和危险操作说明。版本由 0.18.1 按 MINOR 升级到 0.19.0。

## 验证要求

- `scripts/test.ps1 -CI` 必须在版本升级后再次通过。
- 独立 UI runner 必须在可前台激活应用的解锁桌面重跑；当前宿主若阻止前台输入，记录为 FAIL/SKIP，不能用进程内属性赋值替代。
- 生成 0.19.0 便携包、安装器和 SHA-256，并执行当前环境允许的便携、安装、启动、卸载 smoke。
- 签名、物理多屏/缩放、热插拔、休眠/时区、Explorer 重启和真实覆盖升级缺少证据时明确 SKIP。
- 未满足七类发布门禁时只保留候选工作区/资产，不创建稳定标签或 GitHub Release。

## 后续范围

PDF/Office、OCR、语义检索、云同步、通用聊天、外部角色包、3D、商城、账号和遥测仍不在本版范围。进一步功能扩展需以 0.19.0 的真实桌面可用性验证为前提，重新建立版本计划。
