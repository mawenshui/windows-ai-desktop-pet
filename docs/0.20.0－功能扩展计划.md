# 0.20.0 功能扩展计划

本版本聚焦“智能更新与设置减负”，详细决策、顺序和验收标准以[0.20.0 智能更新与易用性优化设计](0.20.0－智能更新与易用性优化设计.md)为准。

## 实施顺序

1. 内置 GitHub 元数据与下载分级路由。
2. 固定仓库/标签/资产与重定向安全校验。
3. ViewModel 智能线路状态和失败恢复。
4. 设置页移除自定义代理/Token 专业配置。
5. 旧设置兼容与模板清理。
6. 自动化回归、文档、版本、打包与候选验证。
