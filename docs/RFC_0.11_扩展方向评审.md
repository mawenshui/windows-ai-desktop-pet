# 0.11 扩展方向 RFC 决策

| RFC | 决策 | 当前交付 |
| :--- | :--- | :--- |
| RFC-SRCH-001 正文/OCR/语义搜索 | **分阶段，默认关闭** | 0.11 只交付文件名增量索引、分页与可解释排序。正文仅允许在用户逐范围授权后扩展；OCR/向量模型未锁定依赖、许可和资源预算，因此不读取正文、不上传文件。 |
| RFC-PET-001 3D 角色 | **暂缓** | 保持已验证的 CC0 2D 回退。Styloo Chibi 在透明 WPF、GPU/内存基线和许可证复核通过前不进入安装包。 |
| RFC-NAV-001 第二扩展页 | **通过** | 定义为离线“维护”页，提供不含凭据的备份/恢复、白名单诊断和可重建缓存清理；无账号、商城或遥测依赖，可随时回退。 |
| RFC-AI-001 用户 Provider 预设 | **受控通过** | schema v1 解析器已实现；要求唯一 ID、HTTPS（本机回环除外）、无 URL 凭据和查询参数。设置默认不启用外部预设，元数据不会覆盖已保存配置。 |
| RFC-HELP-001 在线帮助 | **暂缓** | 离线手册继续作为唯一正式帮助入口。待官网归属、隐私告知和链接失效策略冻结后再启用设置中的功能门。 |

## 安全与退出策略

- 新增功能均保持本地优先；备份明确不含 Windows 凭据管理器中的 API Key。
- 搜索监视器只处理已经授权的目录；缓冲区溢出时转为可取消全量重建。
- 自定义 Provider 文件失败时不污染内置目录或用户现有配置。
- 3D、OCR、语义模型和在线帮助没有通过门禁，因此本版不伪装为可用功能。
