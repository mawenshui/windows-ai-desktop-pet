# 0.18.0－功能扩展计划

> 版本定位：完善本地搜索从“找到结果”到“继续处理”的日常操作闭环。围绕当前选中结果增加清晰、可访问的操作区，支持打开、在文件资源管理器中定位、复制完整路径和加入快捷入口；不增加文件修改、云端或商业化能力。

## 1. 当前状态与目标

0.17.0 已支持授权范围、名称/路径/受控正文查询、类别筛选、固定、最近使用排序和分页，但搜索结果的后续操作仍隐藏在双击和回车中。用户无法从界面发现如何定位原文件、复制路径或把常用结果加入快捷入口；索引刷新后，当前选择也缺少明确的保留规则。

0.18.0 的目标是把搜索结果变成可连续操作的工作入口，同时保持现有权限和隐私边界：

- 选中结果后显示固定位置的操作区，避免依赖鼠标双击知识。
- 所有动作先重新检查目标是否存在，不对文件执行修改、移动、删除或重命名。
- 打开和定位只调用 Windows 用户态 Shell；复制路径只在用户主动操作时写入剪贴板。
- 加入快捷入口复用现有去重、持久化和失效处理，不新增第二套收藏数据。
- 相同查询刷新时按范围与完整路径恢复选择；查询条件改变时清除旧选择，避免对过期上下文执行操作。

## 2. 按顺序实施

### SRCH-180-01 结果选择与可见操作区（P0）

1. 为结果列表增加双向选择绑定，在结果下方显示当前目标名称、类型与大小摘要。
2. 提供“打开”“定位”“复制路径”“加入快捷入口”四个明确按钮；沿用现有配色、焦点样式和紧凑弹窗布局。
3. 操作区只在存在选中结果时显示；按钮具备 UI Automation 名称、可见焦点和至少 36 px 的点击高度。
4. 保留双击结果和回车打开行为，使原有高效路径不受影响。

**验收**：鼠标单击或键盘选择结果后可看见并执行四项操作；没有选择时不显示无效操作区；原有双击和回车仍可打开结果。

### SRCH-180-02 安全 Shell 操作（P0）

1. 将打开、资源管理器定位和剪贴板写入收敛到可测试的系统动作服务，由 ViewModel 统一调用。
2. 打开使用系统默认关联程序；定位使用 `explorer.exe /select,` 并正确传递含空格、中文及特殊字符的路径。
3. 复制路径只复制当前完整路径，不自动访问网络或写入日志、设置、诊断与 AI 请求。
4. 系统调用失败时只返回稳定、可操作的中文提示，不把异常堆栈或敏感路径写入用户状态。

**验收**：文件与文件夹操作参数正确；特殊字符不会被解释为命令；系统调用、剪贴板失败均不会使应用崩溃或泄露路径。

### SRCH-180-03 快捷入口与失效恢复（P0）

1. “加入快捷入口”复用现有 `ShortcutStore`、目标类型识别和名称生成逻辑。
2. 已存在的目标沿用现有重复提示，不静默创建重复记录。
3. 打开、定位和加入快捷入口前重新检查目标；目标失效时禁用相关按钮并显示“目标已不存在，请刷新或重建索引”。
4. 失效结果仍允许复制路径，便于用户排查或重新定位；不自动删除索引记录。

**验收**：可从结果创建文件、文件夹或应用快捷入口；重复和失效目标有稳定反馈；复制失效路径仍可使用。

### SRCH-180-04 选择生命周期、回归与文档（P0）

1. 相同查询因索引修订或手动重新搜索而刷新时，按 `RangeId + FullPath` 恢复当前选择；目标不再出现时清除选择。
2. 查询词、类别、范围、字段、通配符、正则或正文搜索模式改变时立即清除旧选择。
3. 补充动作服务、ViewModel 命令状态、选择保留/清除、快捷入口复用和 XAML 可访问性测试。
4. 同步 PRD、工程规范、技术设计、用户手册、测试计划、当前状态、README 和变更日志。

**验收**：刷新不会无故跳到另一结果；条件改变不会留下旧操作目标；完整自动化验证通过，用户文档与实际行为一致。

## 3. 自动化与发布门禁

1. 先运行定向单元与 WPF 结构测试，覆盖路径参数、异常隔离、命令可用状态和选择生命周期。
2. 依次运行 `scripts/validate-project.ps1` 与 `scripts/test.ps1 -CI`，不得删除、跳过或放宽已有有效断言。
3. 使用 `scripts/bump-version.ps1` 升级至 `0.18.0`，同步版本元数据和发布文档后再次运行完整自动化。
4. 运行 `scripts/package.ps1`，生成便携版、安装版和 `SHA256SUMS.txt`；执行便携启动、安装/升级/卸载、搜索操作、托盘、自启和帮助入口烟雾测试。
5. UI E2E、性能、安全、签名及硬件条件按实际环境记录 PASS、FAIL 或 SKIP；只有正式发布门禁全部通过时才创建稳定 GitHub Release。

## 4. 明确不在本版本实施

- 文件重命名、移动、删除、批量操作和内置文件编辑器。
- 全文预览、PDF/Office/OCR、AI 摘要、语义检索和云端索引。
- 右键 Shell 扩展、管理员权限操作和绕过 Windows 安全提示。
- 快捷入口云同步、团队共享、在线市场、订阅和计费。
