# 0.18.1－功能扩展计划

> 版本定位：在 0.18.0 已有能力上完成一次面向日常使用的交互修订。重点减少无效点击、重复操作和“是否已经保存”的判断成本；不增加数据格式、外部依赖、网络权限、商业化或新的产品模块。

## 1. 当前状态与目标

0.18.0 已形成搜索、快捷入口、待办提醒、AI 配置、维护和在线更新的完整功能骨架，但当前代码仍存在几类可用性缺口：搜索词只能手动删空，已经加入快捷入口的结果仍显示可执行的加入按钮；全局快捷键、自动备份和更新设置在修改后没有统一的未保存状态；快捷入口管理器在无有效选择或扫描期间仍允许触发部分无效操作；待办标题为空时仍可点击保存并在提交后才收到错误。

0.18.1 的目标是让界面状态与实际可执行动作保持一致：

- 用户能从界面直接清空搜索，并在清空后继续输入；结果是否已经加入快捷入口一眼可见。
- 所有显式保存型设置都明确区分“有修改”和“已保存”，保存按钮只在确有可提交修改时启用。
- 快捷入口管理器根据选择数量、排序边界和扫描状态启用操作，避免静默无响应。
- 待办编辑器在必填内容有效时才允许保存，保持现有详细校验和错误提示。
- 所有改动沿用当前本地隐私、文件不修改、凭据安全存储和可访问性边界。

## 2. 按顺序实施

### UX-181-01 搜索连续操作与结果状态（P0）

1. 在搜索框内增加可见的“清空搜索”按钮，只在搜索词非空时显示。
2. 清空后同步取消当前结果选择、刷新空查询结果，并把键盘焦点留在搜索框，方便立即输入下一次查询。
3. 为所选结果计算快捷入口状态：未加入时显示“加入快捷入口”，已经存在时显示“已在快捷入口”并禁用重复提交。
4. 快捷入口新增、编辑、重新定位、移除或重新加载后，立即刷新所选结果的按钮文字与命令状态。
5. 保留双击、Enter、打开、定位和复制路径等现有路径；不修改、移动、删除搜索结果文件。

**验收**：搜索词非空时可一键清空并继续输入；清空后旧结果动作消失；同一目标不会因重复点击创建第二条快捷入口；快捷入口状态在当前会话内实时更新。

### UX-181-02 显式保存设置的状态一致性（P0）

1. 分别跟踪全局快捷键、自动备份和更新检查三组设置的已保存基线。
2. 字段与基线不同时，按钮显示“保存…（有修改）”并启用；保存成功或刚加载设置时显示“已保存”并禁用。
3. 校验或写入失败时保留输入和未保存状态，方便原地修正后重试。
4. GitHub 访问令牌继续独立保存到 Windows 凭据管理器，不纳入普通设置的明文基线。

**验收**：三组设置均能准确反映未保存修改；无修改时不会重复写盘；失败后不会把输入误标为已保存；重新打开应用时状态从实际落盘值建立。

### UX-181-03 快捷入口管理器的上下文操作（P0）

1. 增加当前筛选结果数和选择数提示；筛选切换、选择变化和数据重载后实时更新。
2. “移入分组”“固定”“移除”只在至少选择一项时启用；“重新定位”和排序只在单选时启用。
3. 上移、下移在列表边界或跨固定区边界时禁用；固定按钮根据当前选择显示“固定”或“取消固定”。
4. 失效扫描期间禁用重复扫描并启用“取消检查”，结束或取消后恢复；撤销按钮只在确有可撤销记录时启用。
5. Delete 键复用现有批量移除预览，不绕过确认，也不删除原文件。

**验收**：无效操作无法触发且不再静默失败；多选、筛选、拖动和 Alt+方向键仍可用；扫描按钮状态与后台任务一致；Delete 只打开安全预览。

### UX-181-04 待办编辑的有效保存状态（P0）

1. 待办编辑器只在已打开、数据存储可用且标题包含有效文字时启用保存。
2. 标题变化和编辑器开关立即刷新命令状态；空白标题不再产生一次可预防的失败提交。
3. 日期、时间、重复规则、提醒项必填时间等现有详细校验仍在保存时执行，并保留原有错误反馈。

**验收**：新建和编辑待办时，空白标题无法保存；填写有效标题后无需切换焦点即可保存；其他校验行为与 0.18.0 一致。

### UX-181-05 回归、文档与版本交付（P0）

1. 增加 ViewModel 命令状态、重复快捷入口、设置脏状态、快捷管理器结构和待办保存条件的自动化回归。
2. 同步 PRD、工程规范、技术设计、用户手册、测试计划、README、CHANGELOG 和当前状态。
3. 使用 `scripts/bump-version.ps1` 升级至 0.18.1，再运行完整 `scripts/test.ps1 -CI`。
4. 生成便携版、安装版和 SHA-256 清单，执行当前环境可完成的安装、启动、卸载与便携运行烟雾测试。
5. UI、性能、签名及物理环境条件按实际结果记录 PASS、FAIL 或 SKIP；只有所有正式门禁满足时才创建稳定 GitHub Release。

**验收**：新增行为有自动化覆盖；版本与文档一致；构建、测试、打包和远端状态都有本次证据，不沿用历史结论。

## 3. 明确不在本版本实施

- 新搜索数据源、OCR、语义搜索、文件预览或文件编辑。
- 新待办类型、云同步、团队协作或通用 AI 聊天。
- 新更新源、第三方代理内置列表或绕过 HTTPS 与 SHA-256 校验。
- 新角色包、插件系统、账号、订阅、广告、商城或遥测。
- 设置 schema、待办 schema、备份格式和 AI 配置包格式变更。
