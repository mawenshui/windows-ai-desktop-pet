# 后续功能扩展计划

更新：2026-09-08。设计基线为已同步至 `main` 的 0.13.0 候选；EXT-09/10 已进入 0.14.0 候选工作区。本文只规划本地、通用、可长期维护的能力，不考虑会员、付费素材、广告、商城、云同步、账号体系、商业插件市场或数据变现。

规划按“先缩短每天都要走的路径，再保护本地数据，最后补系统适配”的顺序推进。功能写入计划不等于已经交付；实现状态、自动化结果和实机门禁分别记录。

## 1. 取舍原则

1. **高频优先**：优先减少打开搜索、记录待办、恢复数据所需的点击和等待。
2. **本地优先**：默认不联网、不登录、不上传查询、路径、待办或备份。
3. **明确可控**：全局快捷键可停用、可改键；自动备份可关闭、可查看、可手动立即创建。
4. **失败不破坏**：快捷键冲突时整组回滚；备份失败不影响启动，且不删除已有有效备份。
5. **复用现有能力**：复用当前搜索、待办编辑、事务备份和托盘入口，不引入键盘钩子、后台服务或新第三方依赖。
6. **无障碍一致**：新增入口提供键盘、托盘或页面替代路径，不把功能只藏在手势或颜色中。

## 3. 本轮详细设计

### EXT-09 全局快捷唤出与快速记录

- 设置保存 `enabled`、`searchGesture`、`quickTodoGesture`，采用设置 schema 4；旧设置迁移时保留原字段。
- 快捷键必须包含 `Ctrl`、`Alt`、`Shift` 或 `Win` 中至少一个修饰键和一个普通键。两项不能重复；不接受单独修饰键、Esc、Tab、Enter、Backspace 或 Delete。
- 使用 Windows `RegisterHotKey`/`WM_HOTKEY`，不安装低级键盘钩子，不读取其他输入。
- 搜索快捷键显示桌宠和工具窗，进入主页并聚焦搜索框；快速记录快捷键进入待办、新建编辑器并聚焦标题。
- 如果 AI 设置有未保存修改，沿用现有保存/放弃/取消对话框；取消时保持编辑现场，不强制切页。
- 任一组合被其他程序占用时，本次注册整体回滚，设置页和托盘提示失败；应用仍可正常使用。

### EXT-10 每日本地自动备份

- 自动备份目录为当前账户数据目录下的 `automatic-backups`；文件名包含 UTC 时间，避免本地时区回拨造成覆盖。
- 备份设置、窗口位置、待办/提醒队列、快捷入口/自定义图标和 AI Provider 预设；明确排除 API Key、搜索索引和诊断日志。
- 启动完成数据恢复后检查是否需要创建；距上一份有效自动备份不足 24 小时则跳过。手动“立即备份”不受 24 小时间隔限制。
- 使用现有备份 v2 清单、SHA-256、容量及路径约束，先写临时文件，再原子替换。只有新备份成功后才按时间删除超出保留数的旧自动备份。
- 自动失败在维护页保留状态，并通过托盘给出非阻断提示，不弹阻断启动的对话框；恢复仍需用户从维护页选择文件并确认，不自动覆盖正式数据。

## 4. 明确不做的方向

当前不规划付费角色、皮肤商城、广告、会员、账号/团队、云端待办、云备份、跨用户画像、执行任意脚本的插件、通用聊天、自动操作文件、加密货币或金融功能。内容检索和外部宠物包继续保留在 `tests/prototypes`，没有通过独立 RFC 前不接入产品。

## 5. 交付规则

本轮已按 MINOR 升级为 0.14.0，并同步 PRD、工程/技术设计、手册、测试计划、变更记录和候选报告。完整自动化 249/249、Release 构建、打包以及正常 Windows 会话下的便携/安装/卸载烟雾已通过；独立 UI 与性能交互门禁因当前桌面无法置前或定位控件而 FAIL。全局快捷键真实占用冲突、签名和物理设备矩阵按实际条件保留 SKIP。门禁不齐只提交候选代码和资产，不创建正式标签或 GitHub Release。
