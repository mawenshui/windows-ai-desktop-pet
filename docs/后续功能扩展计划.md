## 2. 接下来的执行顺序

1. **先关闭 EXT-00 的外部门禁**：在解锁、同桌面 Windows 会话运行八组选择器、未保存导航、焦点恢复、真实托盘；核验透明窗口、签名、硬件/升级矩阵及两类包。每份证据重新绑定最终提交和资产，旧 FAIL/SKIP 不能替换为推断 PASS。
2. **复验 B 的实际数据流程**：用隔离账户完成旧数据升级、备份恢复、独立提醒规则跨睡眠/时区、AI 主动测试和卸载保留/清理两分支，核对原文件和凭据边界。
3. **复验 C 的真实输入和常驻负载**：100 个快捷入口、20,000/100,000 索引、大目录改名/撤销、同时到期和静默恢复，观察取消反馈及资源指标；不放宽冻结预算。
4. **D 仅在 RFC 通过后转产品**：内容检索先限定真实纯文本需求与数据删除语义；2D 管理先补完整 schema/状态兼容、启用事务和许可矩阵。没有日期承诺或预占下一版本号。

## 3. 原验收目标保留

- EXT-00：缺报告/旧版本/FAIL 必须拒绝；真实鼠标键盘、两类包和远端下载哈希有证据，不发布 dirty。
- EXT-01：旧数据可迁移，普通待办不自动完成，独立重复项最后一次提交后才结束；错过不风暴、最早时刻去重。
- EXT-02：损坏/超大/越界 ZIP 不改正式目录，中断可恢复、图标不丢、日志根正确，恢复先停写，凭据不备份。
- EXT-03：models 成功/chat 失败、未知模型、非 JSON、拒绝/限流/取消覆盖；旧测试不能保存新字段，导入不激活/发请求。
- EXT-04：重启变更、目录子树、撤销竞争及溢出无越权残留；分页稳定，明确可见匹配依据，不读取正文。
- EXT-05：100 项仍可用、顺序重启保持、批量仅删引用且可撤销、失效扫描可取消，图标依赖受保护。
- EXT-06：同时到期每项保留、静默及重启准确；清历史不删待办，不宣称用户已读或退出后准点。
- EXT-07/08：原型通过后给出是否转产品的决定；未通过隐私/许可/性能/依赖门禁不写成正式功能。

## 4. 暂不排期与交付定义

账户/云同步、跨平台、执行型插件、自动操作文件、通用聊天、OCR/Office/向量检索、3D、商城和自动更新仍无本次交付承诺。

本次按照功能扩展升级 MINOR 为 0.13.0，仍为候选。自动化测试、独立实机、文档、两个包、哈希、最终提交/远端同步及正式资产均齐备才可标为正式交付；当前证据见[0.13.0 报告](release/0.13.0-test-report.md)。
