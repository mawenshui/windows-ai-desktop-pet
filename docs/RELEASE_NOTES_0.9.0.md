# Windows AI Desktop Pet 0.9.0 发布说明

- 发布日期：2026-08-29
- 版本类型：Minor（向后兼容的提醒能力扩展与 UI 修复）
- 状态：发布候选

## 新增能力

- 新增与普通待办分离的独立提醒项。每项可单独开启桌宠漫游、桌宠气泡，也可同时开启或全部关闭。
- 提醒气泡直接显示在桌宠窗口内，桌宠漫游或用户拖动时保持跟随；关闭 Windows 动画效果时只跳过漫游。
- 独立提醒项成功投递后自动转为“已完成”，并保留原定提醒时间和 `Delivered` 状态；投递失败时保持未完成，便于诊断或重试。
- AI 创建草稿只有提醒时间、没有截止时间时，确认卡明确显示“创建提醒项”，确认后默认开启桌宠气泡。

## 修复

- 统一修复搜索范围、搜索结果类别、待办状态、AI 操作目标和 AI 供应商下拉框：选择后可见文字、绑定值和业务行为保持一致。
- 保留并回归验证 0.8.2 的 AI 供应商切换、连接测试通过后保存、待办中文输入可见性和快捷入口空状态修复。

## 兼容性与隐私

- `todos.json` 继续使用 `schemaVersion = 1`，新增字段采用向后兼容的默认值；旧记录缺少 `IsReminder` 时按普通待办读取。
- 普通待办提醒保持原语义：触发后不自动完成，仍可完成、稍后提醒或打开详情。
- AI Key 继续只保存于当前 Windows 账户保护的凭据存储。提醒标题、备注、时间、搜索词和路径不进入日志或普通诊断数据。
- 本版本未新增第三方依赖。

## 验证

- `pwsh -NoProfile -File scripts/test.ps1 -CI`：通过结构、版本、UTF-8 与 146 项自动化测试门禁。
- `dotnet test src/AiPet.sln --configuration Release --no-restore --nologo`：146 项测试通过，0 失败，0 跳过。
- 新增回归覆盖：提醒项字段往返、四种桌宠通道组合、成功投递后自动完成、失败不完成、普通待办状态隔离、AI 提醒分类，以及所有共享下拉框的实际选择。
- WPF 实际渲染快照已检查普通待办页和提醒项编辑器；提醒项开关、文案和滚动布局可见。
- `scripts/package.ps1`：成功生成最终便携 ZIP、Inno Setup 安装程序和 SHA-256 清单。
- 最终便携 ZIP 的 `--smoke` 通过；隔离目录静默安装、安装后自检和静默卸载退出码均为 0，覆盖资源、搜索、快捷项、9 个 AI 预设、凭据往返、自启读取和离线手册。
- 系统托盘提醒、桌宠真实漫游/跟随、系统通知抑制、休眠恢复和多显示器仍需在普通交互式 Windows 会话完成人工验证。
