# Windows AI 桌面宠物 0.24.0 正式版说明

日期：2026-09-17。0.24.0 是“每日复盘与 Markdown 日志”正式版本，GitHub 标题和更新说明使用 UTF-8 中文。

## 本版变化

- 待办页顶部新增“清单 / 复盘”二级切换，默认仍进入清单，保持四个主页面。
- 复盘按日期显示已完成、待处理、已安排数量和相关事项只读标题；当天实时投影，跨日冻结最小快照，不复制或改写待办。
- 每日正文最多 4,000 字，停止输入 500 ms 后自动保存；`Ctrl+S` 可立即重试，历史默认只读并可明确编辑。
- 可逐日删除复盘，页内确认明确说明待办不受影响。
- 用户可显式导出 UTF-8 无 BOM、LF 的单日 Markdown，默认名 `YYYY-MM-DD.md`；不创建默认导出目录或隐式搜索授权。
- `journal.json` schema 1 进入手动/每日自动备份、恢复事务和卸载清理，但不进入 AI、搜索、日志、诊断或遥测。
- 本版明确不包含 Codex、Claude Code 或任何 AI Agent 状态指示、Hooks 和状态文件读取。

## 升级与兼容

设置 schema 5、待办 schema 4、通知 schema 1、快捷入口 schema 1 均不变；新增独立复盘 schema 1。旧版本启动后会在首次进入当前装配流程时创建活动日期元数据，不迁移或重写既有待办。没有新增第三方依赖、网络权限、账号、云同步或遥测。

## 验证与发布边界

源码提交 `2a1f8b1` 的 349/349 自动化、干净打包、系统边界与便携/安装/卸载烟测通过；便携 ZIP SHA-256 为 `3cc1b70d297d66c8dc7dde41db4468dda6c3246f17117a9ea5a0ae1a883a7686`，安装器为 `a1551cb78e6aef3df63e88b1ee7999f82c4c925f25cb19f3a5fbc74c825c1c84`。真实前台 UI 与强制性能因当前桌面不能置前应用而未完成；200% 缩放、系统文件覆盖确认、跨午夜/改时/时区/DST/休眠、代码签名、物理多屏和覆盖升级仍需分别验证。完整 PASS/FAIL/SKIP 见 [0.24.0 验证报告](release/0.24.0-test-report.md)，正式 Release 状态不改变这些证据结论。
