# 当前代码状态与文档索引

日期：2026-09-17；软件基线：**0.24.0 正式版**，由 0.23.0 按 MINOR 升级。本版按 JOURNAL-01～08 增加本地每日复盘与 Markdown 日志，不新增主页面、第三方依赖、账号、云端、遥测、权限或 Agent 状态指示。

## 当前实现

| 部分 | 当前能力 |
| :--- | :--- |
| 桌宠与工具窗 | 四个 RGS 角色、主页/待办/维护/设置四页、托盘、自启、全局快捷键、离线手册与主题保持不变 |
| 搜索与快捷入口 | 授权范围、受控正文、结果动作、分页/固定/最近使用与快捷管理能力保持不变 |
| 待办、提醒与复盘 | 待办页新增清单/复盘二级视图；复盘显示本地当天摘要和只读事项标题，正文 500 ms 自动保存、支持 `Ctrl+S`、跨日快照、历史浏览/编辑/逐日删除及显式 Markdown 导出；待办与提醒既有能力保持 |
| 数据与维护 | 新增 `journal.json` schema 1 和 `DataModule.Journal`，进入手动/自动备份、恢复事务、回滚与卸载清理；设置 5、待办 4、通知 1、快捷入口 1 不变 |
| 隐私 | 复盘正文和快照不进入 AI、搜索、日志、诊断或遥测；导出目录不自动获得搜索授权；删除复盘不持有 TodoStore 写路径 |

复盘最多 3,650 天、每日 4,000 字和 256 个最小事项快照，总文件限制 32 MiB。存储使用原子替换、`.previous`、损坏后阻止空写和期望 revision；Markdown 固定 UTF-8 无 BOM、LF、默认 `YYYY-MM-DD.md`，只由用户确认保存对话框后写入。Codex/Claude Code 等 Agent 状态、Hooks 和状态文件读取明确不在实现中。

## 当前验证边界

复盘回归已覆盖存储往返、过期 revision、损坏与容量保护、投影、跨日冻结、删除隔离、Markdown 编码/标题净化/路径保护、手动/自动备份恢复、ViewModel 自动保存及 WPF 合同。干净源码提交 `2a1f8b1` 的完整 `scripts/test.ps1 -CI` 为 349/349、0 警告、0 错误；正式打包、哈希复核、系统边界以及便携/安装/卸载烟测通过，细节见 [0.24.0 验证报告](release/0.24.0-test-report.md)。

真实前台复盘交互与强制性能因当前桌面不能置前应用而未完成；200% 缩放、系统覆盖确认、跨午夜/手动改时/时区/DST/休眠、多屏、签名和覆盖升级不能由进程内自动化推断。正式资产 provenance 为 clean/unsigned。GitHub 已补齐 0.1.0～0.24.0 共 34 个正式 Release，并核对中文标题、中文正文、标签、资产大小与 SHA-256 digest；v0.24.0 为唯一 Latest。
