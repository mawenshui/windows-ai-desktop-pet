# 当前代码状态与文档索引

日期：2026-09-13；软件基线：**0.18.1 候选版本**，由 0.18.0 按 PATCH 升级。本版只完善现有搜索、设置、快捷入口管理和待办编辑的界面状态与操作逻辑，没有新增商业化、云端、账号、依赖、权限或数据格式。

## 当前实现

| 部分 | 当前能力 |
| :--- | :--- |
| 桌宠/窗口 | RGS 四预设、四页工具窗、常驻/置顶、页内选择、未保存 AI 编辑保护、离线帮助 |
| 搜索 | 授权元数据索引、名称/相对路径、筛选/分页/固定/历史、监听重建、可选受控正文；结果可打开/定位/复制/加入快捷入口，支持保持焦点的一键清空和已加入状态 |
| 快捷入口 | 可由搜索结果直接创建；分组、固定、多选、拖动/键盘排序、失效扫描、重新定位、批量移除预览和撤销；管理动作随选择、边界与扫描状态启用 |
| 待办/提醒 | 六种筛选、标题有效时保存、日历重复、多次时间、规则时区、单项 AI 草稿、今日安排、持久提醒中心、静默/汇总/稍后 |
| 设置/维护 | 全局快捷键、自动备份和更新检查显示有修改/已保存；AI 多配置、加密完整配置包、事务恢复、诊断、缓存清理 |
| 在线更新 | 启动检查稳定 GitHub Release，可选周期、系统代理和可信 HTTPS 加速；私库令牌仅安全保存后使用，安装器须通过 Release SHA-256 清单 |
| EXT-08 | 外部 2D 角色包仍只在 `tests/prototypes` 隔离评估，未接入应用或发行包 |

搜索清空保留当前类别与范围，并在 UI 命令结束后恢复 SearchBox 焦点。结果快捷入口状态通过现有 `ShortcutStore` 派生，不新增收藏数据。显式保存基线只包含非敏感设置；校验或写入失败不推进基线。GitHub 令牌继续独立保存在 Windows 凭据管理器。

快捷管理器使用统一纯状态计算选择数、固定区排序边界、扫描互斥和撤销可用性；Delete 只进入现有移除预览。待办保存按钮只预防空白标题提交，日期、时间、重复与提醒规则仍由原保存路径验证。设置维持 schema 5，待办维持 schema 4，快捷入口维持 schema 1。

## 当前验证边界

版本升级前后两次 `scripts/test.ps1 -CI` 均完成。升级后结构与 UTF-8 校验、发布证据反例、Release 全解决方案构建及 **302/302** 单元/集成测试为 PASS，构建 0 警告、0 错误。新增覆盖搜索清空与重复状态、三组设置基线、快捷管理选择/边界/扫描状态、Delete 安全入口、待办空白标题和 WPF 可访问结构。

最终候选已从干净源提交 `9b8b1a96e4ebac66531ebe5719b0e12568b4a5b8` 重新生成。受限沙箱中的首次便携 smoke 因 Windows Credential Manager 报告“登录会话不存在”而退出码 2；在普通 Windows 用户会话重跑后，便携运行、静默安装、安装后启动、静默卸载及本安装位置自启项清理均通过。独立 UI 与性能测试在发送真实输入前因应用无法成为前台窗口而停止并记为 FAIL；安装器和便携主程序未签名，记为 SKIP；多屏、缩放、热插拔、休眠、时区/时钟、Explorer 重启和升级保留缺少本轮实机见证，记为 SKIP。具体哈希及环境见本版验证报告，因此当前不能创建稳定 `v0.18.1` Release。
