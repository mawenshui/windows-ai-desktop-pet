# 当前代码状态与文档索引

日期：2026-09-12；软件基线：**0.18.0 候选工作区**，由 0.17.0 按 MINOR 升级。本版完善搜索结果的后续操作，没有新增商业化、云端、账号或文件修改能力。

## 当前实现

| 部分 | 当前能力 |
| :--- | :--- |
| 桌宠/窗口 | RGS 四预设、四页工具窗、常驻/置顶、页内选择、未保存 AI 编辑保护、离线帮助 |
| 搜索 | 授权元数据索引、名称/相对路径、筛选/分页/固定/历史、监听重建；可选受控正文；结果选中后可打开、资源管理器定位、复制路径或加入快捷入口，相同查询刷新恢复选择 |
| 快捷入口 | 可由搜索结果直接创建；分组、固定、多选、拖动或键盘排序、失效扫描、重新定位、批量移除预览和本次运行内撤销 |
| 待办/提醒 | 六种筛选、日历重复、多次时间、规则时区、单项 AI 草稿、今日安排、持久提醒中心、静默/汇总/稍后 |
| AI/维护 | 多配置与能力验证；加密完整配置包迁移全部配置、Provider 预设和 Key；模块备份、事务恢复、诊断、缓存清理 |
| 在线更新 | 启动检查稳定 GitHub Release，可选周期、系统代理和可信 HTTPS 加速；私库令牌仅安全保存后使用，安装器下载须通过 Release SHA-256 清单 |
| EXT-08 | 外部 2D 角色包仍只在 `tests/prototypes` 隔离评估，未接入应用或发行包 |

正文搜索默认关闭，只处理已有授权范围内不超过 128 KiB 的 `.txt`/`.md`，每范围最多 1,000 个正文文件和 16 MiB。普通文字可匹配正文；通配符和正则只处理元数据。正文索引是本机派生数据，不进入普通/自动备份、诊断、日志、更新或 AI 请求，停用或撤销范围会清除对应数据。

结果选择只保存在当前内存会话。打开和定位通过可测试 Windows 动作适配器执行，路径作为单个参数传递；失效目标仍可复制路径。TodoDocument 维持 schema 4，设置维持 schema 5，无数据迁移或新增依赖。

## 当前验证边界

版本升级后 `scripts/test.ps1 -CI` 已完成：结构与 UTF-8 校验、发布证据反例、Release 全解决方案构建及 **297/297** 单元/集成测试均为 PASS，构建 0 警告、0 错误。搜索结果动作参数、稳定失败提示、命令状态、失效目标、快捷入口复用、选择生命周期和 WPF 可访问入口已加入回归。

远端 `main`、Release 列表和 0.18.0 资产将在本轮本地实现、测试及打包完成后核对；未通过全部正式门禁时不创建稳定标签或 Release。
