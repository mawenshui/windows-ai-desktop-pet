| 部分 | 当前能力 |
| :--- | :--- |
| 桌宠/窗口 | RGS 四预设、四页工具窗、常驻/置顶、页内选择、未保存 AI 编辑保护、离线帮助 |
| 搜索/快捷入口 | 授权元数据索引、名称/相对路径、筛选/分页/固定/历史、监听重建、分组/排序/批量管理 |
| 待办/提醒 | 日历重复、多次时间、规则时区、AI 草稿、持久提醒中心、静默/汇总/稍后 |
| AI/维护 | 多配置与能力验证；加密完整配置包迁移全部配置、活动项、Provider 预设和 Key，导入后即用；保留无 Key 兼容迁移；模块备份、事务恢复、中断回滚、诊断、缓存清理 |
| EXT-09 | 默认 `Ctrl+Alt+Space` 搜索、`Ctrl+Alt+T` 快速待办；设置可启停/改键，冲突整组回滚，托盘等价入口 |
| EXT-10 | 正常启动执行每日本地自动备份；24 小时节流、保留 1～30 份、手动创建/打开目录、失败保留旧包 |
| EXT-11 | `.aipet-ai-config` 使用 PBKDF2-SHA256 与 AES-256-GCM；导入先预览并整体替换 AI 配置，Key 写入当前账户凭据库，中途失败回滚 |
| EXT-16 | 正常启动检查一次稳定 GitHub Release；可选 1～168 小时周期、系统代理和可信 HTTPS 加速；私有仓库令牌进 Windows 凭据管理器，安装器校验 SHA-256 后由用户确认启动 |
| EXT-07/08 | tests/prototypes 隔离实现及评估，未接入产品和发行包 |

自动备份固定包含设置、窗口位置、待办/提醒、快捷入口/图标及 Provider 预设，排除 API Key、GitHub 令牌、搜索索引和日志；它不等同于用户主动创建的加密完整 AI 配置包。设置为 schema 5；旧设置迁移保留 `.pre-v4.bak` 和 `.pre-v5.bak`。预览/UI 自动化模式不注册系统级快捷键、不写自动备份，也不访问更新网络。
