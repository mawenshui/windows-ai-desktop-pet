# 当前代码状态与文档索引

日期：2026-09-13；软件基线：**0.21.0 候选工作区**，由 0.20.0 按 MINOR 升级。本版按 UX-210-01～19 优化工具窗键盘路径、搜索恢复、待办编辑/撤销、今日安排和可访问反馈；没有新增商业化、云端、账号、依赖、权限或数据格式。

## 当前实现

| 部分 | 当前能力 |
| :--- | :--- |
| 桌宠/窗口 | RGS 四预设、四页工具窗、常驻/置顶、36×36 标题栏控制、`Alt+1`～`Alt+4`/`Ctrl+L`/`Ctrl+N`/`Ctrl+Enter`/`F1`、Esc 页内优先层级、未保存 AI 编辑保护 |
| 搜索 | 授权元数据索引、名称/相对路径、筛选/分页/固定/历史、可选受控正文；结果可打开/定位/复制/加入快捷入口，无结果可一键重置或管理范围，结果数量和选中序号独立更新/播报 |
| 快捷入口 | 可由搜索结果直接创建；分组、固定、多选、拖动/键盘排序、失效扫描、重新定位、批量移除预览和撤销；管理入口静止可见，失效状态含图形和文字语义 |
| 待办/提醒 | 筛选摘要、上下文空态、编辑全字段未保存保护与页内放弃；手动写操作统一可撤销并防并发覆盖；今日安排可选前 12 条/清除；重复、时区、提醒中心语义不变 |
| 设置/维护 | 五项目录滚动并聚焦；更新智能线路；全局快捷键和自动备份显示有修改/已保存；AI 多配置/加密完整包；维护成败有独立 live region，失败反馈不拼接原异常或完整路径 |
| 在线更新 | 启动检查稳定 GitHub Release，官方元数据失败后切换内置 API 线路，下载按三条内置线路和官方地址逐级恢复；固定仓库/标签/资产/主机/大小，安装器须通过可选 digest 与 Release SHA-256 清单 |
| EXT-08 | 外部 2D 角色包仍只在 `tests/prototypes` 隔离评估，未接入应用或发行包 |

搜索普通清空保留当前类别/范围，一次性重置则直接更新三个条件并只触发最终刷新。编辑基线、撤销记录、筛选摘要、结果数量和页签帮助都是进程内视图状态，不进入 settings/todo/shortcut schema。维护状态不写日志或诊断。设置维持 schema 5，待办维持 schema 4，快捷入口维持 schema 1。

页面直接快捷键与设置目录切换都复用 `TrySelectTab` / `TryResolveUnsavedAiChanges`，不绕过 AI 未保存保护。快捷管理器 Delete 继续只进入现有移除预览。待办保存按钮只预防空白标题提交，日期、时间、重复与提醒规则仍由原保存路径验证。设置维持 schema 5，待办维持 schema 4，快捷入口维持 schema 1。
