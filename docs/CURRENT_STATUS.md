## 当前验证边界

`scripts/test.ps1 -CI` 完整通过：结构与证据反例校验、Release 构建 0 警告/0 错误、xUnit 249/249。0.14.0 便携版、安装器、SHA-256 和正常 Windows 会话下的便携/安装/已安装启动/卸载烟雾均通过；系统脚本的可自动执行部分通过。

UI E2E 在 `inline-search-scope` 因当前桌面无法把应用置前而 FAIL，runner 未发送输入；性能强制门禁也因 UI Automation 无法定位已打开的工具窗控件而 FAIL，尽管 20,000 条匿名索引搜索 p95 为 4.6504 ms。Windows 可注册两个默认组合，但隔离候选进程的外部合成按键未触发可见工具窗，因此系统快捷键回调烟雾同样按环境受限 FAIL 记录；物理键盘、实际占用和正常退出释放仍为 SKIP。多屏/缩放、休眠/时区、Explorer 重启、签名、交互卸载和真实跨版本升级也缺相应证据。详细结果和资产哈希见[0.14.0 验证报告](release/0.14.0-test-report.md)。因此只保留候选，不创建 `v0.14.0` 标签或 GitHub Release。
