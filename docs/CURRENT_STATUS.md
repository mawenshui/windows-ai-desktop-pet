# 当前代码状态与文档索引

日期：2026-09-20；当前正式版本：**0.26.0**，由 0.25.2 按 MINOR 升级。安全本地 2D 角色包库、设置 schema 7 与维护事务已实现，本地及 GitHub 两轮必需发布门禁均通过，[v0.26.0](https://github.com/mawenshui/windows-ai-desktop-pet/releases/tag/v0.26.0) 已作为普通正式版发布。UI、性能、签名和物理硬件矩阵保留为可选诊断，不阻断升级、标签或 GitHub Release，但必须如实记录。

## 当前实现

| 部分 | 当前能力 |
| :--- | :--- |
| 专注会话 | 待办页“专注陪伴”支持 15/25/50 分钟及 5～180 分钟自定义时长，可选关联当前未完成待办；支持开始、暂停、继续、提前结束和正常到时，且不自动完成关联待办 |
| 恢复与复盘 | `focus-sessions.json` schema 1 以 revision、原子替换、`.previous` 和损坏写保护保存；重启、休眠和系统时间变化后校准，复盘与 Markdown 显示完成次数、总时长和提前结束次数 |
| 低打扰桌宠 | 运行和暂停时停止自主漫游、随机气泡及朝向跟随；正式提醒仍可显示。可选点击穿透，并可由托盘、打开设置、结束专注或退出恢复交互 |
| 全屏隐藏 | 可选每 500 ms 检查其他应用是否覆盖桌宠所在显示器，经两次一致采样后隐藏；最大化、本应用、不可见、最小化和零尺寸窗口不触发，只恢复自身造成的隐藏 |
| 本机角色库 | 内置 base、hero、skeleton、monster 与用户导入角色共用真实首帧卡片；本地文件夹经身份、SPDX、来源、路径、PNG 和资源预算校验，预览确认后 staging 导入 |
| 切换与回退 | `pet.id + preferredCharacter` 先保存再由 PetWindow 原子替换 manifest/缓存；坏包逐项隔离，活动选择无效回退内置角色；移除前先回退且不修改源文件夹 |
| 数据与维护 | 设置升级为 schema 7 并保留 `.pre-v7.bak`；PetPacks 与 FocusSessions 均进入手动/自动备份、恢复事务、回滚和用户授权的卸载清理 |
| 隐私与商业边界 | 角色包导入完全离线，不访问来源 URL、不执行代码、不记录源完整路径；无商城、支付、账号、广告、商业 DLC、在线下载、3D、音频或插件执行 |
| 更新连通性 | 检查与下载显式共用 Windows 用户代理和标准环境代理；官方失败后使用内置匿名线路。网络失败、匿名源 404 和不安全元数据分别提示；固定仓库、标签、资产、重定向、大小、digest 与 SHA-256 校验不放宽 |
| 主题切换 | light/dark/high-contrast 使用完整语义调色板；主体、卡片、输入、文字、状态色、边框和阴影同时更新，深色切回浅色会写回全部浅色角色 |

专注 UI 倒计时每秒刷新，但只在状态转换、恢复校准和退出检查点写盘。角色包固定为 idle/jump、五个原绘方向与可选 death；单帧最大 512×512/4 MiB，单包最多 1,000 帧、32 MiB 编码和 128 MiB 解码估算，不接受归档、脚本、音频、模型或网络资源。

## 当前验证边界

0.26.0 最终 `automated` 为 380/380、0 跳过、0 警告、0 错误；角色包严格合同、导入事务、损坏隔离、切换/移除、schema 迁移、备份恢复和 XAML 合同回归均通过。由干净源码提交 `a89d499` 生成的便携版、安装、安装后启动、卸载和自启清理 smoke 全部通过；GitHub Release 工作流在标签提交重新执行必需门禁并回下载核对三项资产。完整摘要见 [0.26.0 验证报告](release/0.26.0-test-report.md)。

便携启动、全新安装、安装后启动与卸载清理属于正式发布必验主路径。Windows 凭据存储和真实 AI 在可访问当前用户保管库的授权会话中验证；CI、服务或沙箱登录返回系统错误 1312 时记为环境 SKIP，其他凭据错误仍判为失败。独立 UI 自动化已在发送输入前因当前 Codex 桌面无法把应用置前而安全停止；强制性能中的匿名搜索部分通过，桌面交互指标因同一前台条件未形成 PASS。签名、多屏/缩放、休眠/改时和 Explorer 重启等结果只描述已测环境，不得把未测或失败项目写成 PASS，但它们不阻断正式发布。
