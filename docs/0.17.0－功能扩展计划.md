# 0.17.0－功能扩展计划

> 版本定位：把已通过隔离验证的受控本地文本内容检索接入正式产品，并围绕授权、索引生命周期、结果解释和故障恢复完善现有搜索。该能力默认关闭，不引入云端、商业化、OCR 或语义检索。

## 1. 现状与目标

0.16.1 的本地搜索只索引授权目录中的名称、相对路径、类型、大小和修改时间。仓库中的隔离原型已经验证了单独同意、文件大小限制、严格编码、取消和撤销清理，但正式应用没有正文读取链路、索引状态或正文命中解释。

0.17.0 的目标是让用户在明确开启后，能够用普通文字查找授权目录内的小型纯文本文件，同时始终知道读取范围、索引状态和命中原因，并可随时停用和清除派生数据。

设计原则：

- 默认关闭，正文读取必须由用户在设置中单独开启。
- 只处理已有授权范围，不增加全盘扫描或隐式目录授权。
- 文件名或相对路径命中优先于正文命中，现有搜索习惯保持不变。
- 索引在本机 SQLite 中派生生成，不进入备份、诊断、日志或 AI 请求。
- 停用功能或移除授权范围时立即撤销任务并清除对应正文索引；过期任务不能恢复已撤销的数据。

## 2. 按顺序实施

### SRCH-170-01 受控正文索引（P0）

1. 将隔离原型中的安全边界迁入 `AiPet.Search` 正式模块。
2. 仅支持 `.txt` 和 `.md`；单文件最大 128 KiB，每个授权范围最多索引 1,000 个正文文件、读取正文总量最多 16 MiB。
3. 支持严格 UTF-8（可含 BOM）和带 BOM 的 UTF-16 LE/BE；无法可靠解码、含 NUL、隐藏、系统、重解析点、超限或不可读取的文件只计为跳过，不阻断名称索引。
4. 全量重建使用暂存表并原子替换；取消、失败和授权撤销保留上一份可用名称索引，且不会提交不完整正文。
5. 文件监视器对新增、修改、删除和移动进行正文增量同步；溢出时沿用全量重建恢复路径。

**验收**：边界内文本可检索；不支持、超限、二进制和链接文件不进入正文索引；取消或撤销期间产生的旧任务不能提交正文；移除范围只删除该范围的派生数据。

### SRCH-170-02 正文查询与结果解释（P0）

1. 只对普通文字查询启用正文匹配；`*`、`?` 通配符和 `re:` 正则仍只处理用户选择的名称或相对路径字段。
2. 名称/路径完全、前缀和包含匹配继续使用现有优先级；仅正文命中的结果排在元数据命中之后。
3. 正文命中显示“正文连续包含”和最多 120 个字符的单行上下文摘要；摘要折叠空白，不展示整篇正文。
4. 范围、类别、固定结果、最近使用排序、分页与索引修订刷新继续适用于正文结果。

**验收**：相同查询下元数据结果稳定排在正文结果之前；正文摘要短且可解释；通配符和正则不会进入正文；分页无重复、无越权范围结果。

### SRCH-170-03 设置、状态与恢复操作（P0）

1. 在现有“搜索范围”卡片内增加“文件正文搜索（可选）”，使用原生复选框明确启用，说明支持格式、大小和本地派生数据边界。
2. 启用后为已有授权范围后台重建；显示已索引文件数、跳过数、读取量和运行状态。
3. 提供“重建正文索引”和“停用并清除”操作；进行中的任务可沿用每个范围现有的取消按钮。
4. 状态变化通过可见文本和 UI Automation polite live region 同时反馈；操作具备可访问名称、可见焦点和至少 40 px 的键盘/触控目标。
5. 首页授权说明根据开关明确显示当前只查元数据或会读取受控文本正文，避免与实际行为冲突。

**验收**：默认关闭；一次开启即可构建并搜索；停用后查询立即不再命中正文且数据库正文表为空；重启后按已保存设置恢复；窄窗口和键盘路径可完成全部操作。

### SRCH-170-04 隐私、维护与可诊断性（P0）

1. 正文、摘要、搜索词和完整路径不得进入日志、诊断导出、更新请求或 AI 请求。
2. 正文索引继续属于 `SearchIndex` 派生数据，排除在自动/手动备份之外；维护页清理搜索索引时一并删除正文表和 sidecar。
3. 正文统计只暴露数量、字节量、稳定错误类别和完成时间，不暴露文件名或内容。
4. 更新 PRD、工程规范、技术设计、用户手册、测试计划、当前状态、README 和变更日志，使“是否读取正文”的描述与开关状态一致。

**验收**：诊断和备份测试证明正文不外泄；维护重建可恢复；所有用户文档准确描述默认状态、边界和清除方式。

## 3. 自动化与发布门禁

1. 为编码、扩展名、大小/数量/总量限制、二进制、重解析点、原子重建、取消、撤销和 watcher 增量同步补充单元/集成测试。
2. 为排名、摘要、普通文字/通配符/正则分流、范围、类别和分页补充搜索回归测试。
3. 为设置持久化、首次开启、停用清理、状态反馈、键盘可达和布局增加 ViewModel/WPF 自动化测试。
4. 依次运行 `scripts/validate-project.ps1`、定向测试和 `scripts/test.ps1 -CI`，修复全部失败。
5. 使用 `scripts/bump-version.ps1` 升级至 `0.17.0`，同步代码元数据、安装器和文档，再运行完整自动化测试。
6. 运行 `scripts/package.ps1`，生成便携版、安装版和 `SHA256SUMS.txt`；执行便携运行、安装/升级/卸载、托盘、自启、搜索设置和正文撤销烟雾测试。
7. UI E2E、性能、安全、签名及硬件门禁按实际环境记录 PASS、FAIL 或 SKIP。只有全部正式发布门禁通过时才推送标签并发布稳定 GitHub Release。

## 4. 明确不在本版本实施

- PDF、Office、图片 OCR、压缩包和邮件正文解析。
- 向量数据库、语义搜索、AI 摘要、云端索引和跨设备同步。
- 用户自定义扩展名、无限制大文件、网络共享目录专项适配。
- 商业订阅、用量计费、推荐位或在线内容市场。
