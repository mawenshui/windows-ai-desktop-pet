# Windows AI Desktop Pet 0.19.0 候选说明

日期：2026-09-13。0.19.0 是基于 0.18.1 的向后兼容交互升级；当前仅为候选工作区/资产，完整发布门禁未满足前不创建稳定 Release。

## 主要变化

- 修复主页所选结果操作区与快捷入口共用网格行造成的覆盖；状态、结果操作和快捷入口现在独立布局。
- 标题栏控制扩大到 36×36 DIP；快捷卡管理入口静止可见且为 24×24，失效项使用图形、文字提示和可访问名称共同表达。
- 搜索框可用 `Down` 进入首条结果，首条用 `Up` 返回输入；有查询时 Esc 先清空，`Ctrl+L` 从任意页返回搜索。
- 待办把新建、筛选、编辑器和清单前置；一句话 AI 与今日安排默认折叠，有草稿、澄清或错误时自动展开，折叠不清除状态。
- 设置增加外观、快捷键、更新、搜索、AI 五项目录，选择后滚动并聚焦分组；AI 自动展开，未保存修改保护保持有效。
- 缓存重建采用危险次要样式和独立确认；默认“保留并返回”，文案明确退出、下次重建及不会删除的数据。
- 增加 `Alt+1`～`Alt+4` 直接页快捷键；与 `Ctrl+Tab`、托盘和定向入口共用页面保护逻辑。

## 兼容与隐私

- settings schema 仍为 5，todo schema 仍为 4，shortcuts schema 仍为 1，备份格式仍为 v2；0.18.1 数据无需迁移。
- 不新增依赖、网络端点、遥测、权限或角色素材；搜索授权、正文限制、AI 发送范围、Credential Manager 和更新校验不变。
- 设置目录、折叠状态和焦点位置属于运行时视图状态，不写入个人数据文件。

## 升级说明

可在退出旧版本后直接运行 0.19.0 便携版或安装器。便携版和安装版仍默认使用当前 Windows 账户的 `%APPDATA%/WindowsAiDesktopPet` 数据；交互卸载默认保留个人数据，静默卸载始终保留。
