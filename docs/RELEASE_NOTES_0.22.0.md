# Windows AI Desktop Pet 0.22.0 候选说明

日期：2026-09-14。0.22.0 是“待办聚焦与录入优化”候选版本，不是已发布的稳定 Release。

## 本版变化

- 待办清单增加只在本地匹配标题与备注的查找、`Ctrl+F` 聚焦、查询专用空态、六筛选计数和三种排序。
- 清单改为原生单选列表；刷新按稳定 ID 恢复仍可见事项，动作集中到列表下方的统一操作带。
- 列表支持方向键/Home/End、Enter/F2 编辑、`Ctrl+Enter` 完成或恢复、Delete 可撤销删除；双击仍可编辑。
- 卡片增加非颜色紧迫度文字，选中摘要和各动作使用目标化 UI Automation 名称及动态播报。
- 编辑器增加今天/明天截止、30 分钟后/明天提醒和清除快捷动作，显示标题/备注长度与实时有效性；字段修正后旧提交错误立即消失。

## 升级与兼容

- 设置 schema 保持 5，待办 schema 保持 4，快捷入口 schema 保持 1，不新增迁移确认。
- 待办查找、筛选计数、排序、选择、校验提示和快捷时间草稿只在进程内保留，不进入备份、诊断、日志或 AI 请求。
- 所有单项操作继续复用既有原子写入、并发校验、通知语义和最近一次撤销。
- 不新增外部依赖、网络权限、云同步、账号或遥测。

## 发布边界

候选测试、资产哈希和 PASS/FAIL/SKIP 见[0.22.0 验证报告](release/0.22.0-test-report.md)。前台真实 UI、性能、安全存储、代码签名、物理多屏/缩放、休眠/时区、Explorer 重启、真实覆盖升级、提交/推送和远端 Release 必须分别验证；任一必需门禁不完整时不得发布为稳定版本。
