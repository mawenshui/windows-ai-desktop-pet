# Windows AI Desktop Pet 0.14.0 候选说明

日期：2026-09-08。0.13.0 → 0.14.0 是向后兼容的功能扩展 MINOR。当前为候选版本；完整发布门禁尚未全部通过，没有创建 `v0.14.0` 标签或 GitHub Release。

## 新增

- 默认 `Ctrl+Alt+Space` 从其他窗口打开搜索，`Ctrl+Alt+T` 快速新建待办并聚焦标题。
- 设置页可停用或修改两个组合键；格式和重复项在保存前校验，任一注册冲突会释放本应用的全部全局快捷键。托盘新增“立即搜索”和“快速记待办”。
- 维护页新增每日本地自动备份，默认启用、24 小时最多一次、保留 7 份，可设置 1～30 份、立即创建或打开目录。
- 设置格式升级到 schema 4；迁移前保存 `settings.json.pre-v4.bak`。

## 数据与隐私

全局快捷键只使用 Windows RegisterHotKey/WM_HOTKEY，不安装键盘钩子，不读取或记录其他按键。自动备份复用备份格式 v2、SHA-256 和既有路径/JSON/凭据校验；包含设置、位置、待办/提醒、快捷入口/图标和 Provider 预设，排除 API Key、搜索索引和日志。只有新包成功后才清理超出保留上限的旧包。

自动备份位于当前账户 `%APPDATA%/WindowsAiDesktopPet/automatic-backups`。预览和 UI 自动化模式不注册全局快捷键、不创建自动备份。恢复仍由用户在维护页选择文件并确认，不会自动覆盖正式数据。

## 升级说明

首次读取 0.13.0 或更早设置时会迁移到 schema 4，并保留迁移前副本。默认启用两个全局组合键和每日备份；如组合被占用，应用功能仍可通过桌宠或托盘访问。便携版与安装版继续使用当前 Windows 账户数据目录，API Key 不随备份迁移。

## 验证边界

自动化、打包、烟雾、签名、独立 UI 和物理设备的当次结果见[0.14.0 验证报告](release/0.14.0-test-report.md)。真实跨程序按键、占用/退出释放、透明窗口前台输入、多屏/缩放、休眠/时区、Explorer 重启、签名和交互升级没有证据时，不得写为 PASS。
