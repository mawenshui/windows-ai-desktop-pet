# 0.21.0 功能扩展计划

本版本聚焦“键盘效率、状态恢复与可访问反馈”，详细范围、顺序与验收标准以[0.21.0 键盘与任务流优化设计](0.21.0－键盘与任务流优化设计.md)为准。

## 实施顺序

1. UX-210-01～05：工具窗键盘入口、快捷键说明、Esc 层级与编辑器快速保存。
2. UX-210-06～10：搜索无结果恢复、一次性重置、数量/选择摘要和快捷入口语义。
3. UX-210-11～16：待办筛选摘要、空态动作、编辑保护与统一手动撤销。
4. UX-210-17～18：今日安排批量选择、紧凑控件、时间提示和动态播报。
5. UX-210-19：维护错误分类与隐私安全反馈。
6. 自动化测试、版本、文档、打包与候选验证。
