# 0.25.2 验证报告

日期：2026-09-18  
版本：0.25.2

## 当前结论

0.25.2 修复了自动依赖审计发现的 High 级 SQLite 传递依赖漏洞，并增加可重复、显式授权和全程脱敏的真实 AI 诊断入口。版本与文档同步后的完整自动化回归为 371/371 通过，Release 构建 0 警告、0 错误。正式发布的必需门禁 `automated` 与 `package-smoke` 均已通过；真实 AI、UI、system、performance、signatures 与 hardware 是补充诊断，其 FAIL/SKIP 如实保留但不阻断正式版。

## 缺陷与修复

| 发现 | 修复 | 复验 |
| :--- | :--- | :--- |
| `dotnet list package --vulnerable --include-transitive` 报告 `SQLitePCLRaw.lib.e_sqlite3 2.1.6` 命中 High 级 CVE-2025-6965 | 将直接依赖 `Microsoft.Data.Sqlite 8.0.10` 升级到 .NET 8 维护线 8.0.31，传递解析为 SQLitePCLRaw 2.1.12 | 解决方案 13 个项目复扫均报告无当前 NuGet 已知漏洞；371 项回归、SQLite 搜索往返、系统 smoke 和最终包 smoke 全部通过 |
| 原项目没有可安全重复执行的真实 AI 自动化入口 | 新增 `scripts/test-live-ai.ps1 -AllowSavedCredential`，只在用户授权后读取活动 Windows 凭据，使用生产客户端执行三个只读检查 | 报告只含状态、类别、延迟和数量；Key、端点、模型、配置名、响应正文及生成内容均未输出或落盘，TodoStore 未写入 |

安全公告说明受影响版本为 `SQLitePCLRaw.lib.e_sqlite3 <= 2.1.11`，底层 SQLite 需升级到 3.50.2 或更高：[GHSA-2m69-gcr7-jv3q](https://github.com/advisories/GHSA-2m69-gcr7-jv3q)。当前直接包及依赖关系见 [Microsoft.Data.Sqlite 8.0.31](https://www.nuget.org/packages/Microsoft.Data.Sqlite/8.0.31)。
