## 缺陷结论

问题由两个相互放大的交互缺陷造成：共享自定义 `ComboBox` 模板偏离 WPF 原生选择语义；下拉弹层作为独立顶层窗口出现时，工具窗又可能将其误判为外部失焦并在选择提交前自动收起。0.12.1 恢复原生 `ComboBox` 模板和对象级 `SelectedItem` 绑定，并在任一下拉展开期间暂停自动隐藏，关闭后再按窗口状态重新调度。
