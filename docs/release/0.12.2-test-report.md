## 缺陷结论

此前连续修复 ComboBox 模板、对象绑定和弹层自动隐藏竞争后，用户侧仍无法可靠改变选项，说明问题不适合继续围绕 Popup 生命周期打补丁。0.12.2 取消工具窗口内全部弹出式下拉：短集合改为分段单选，长集合改为可见 `ListBox` 卡片。选择始终发生在原窗口内，因而不存在下拉弹层抢焦点或被自动隐藏的路径。
