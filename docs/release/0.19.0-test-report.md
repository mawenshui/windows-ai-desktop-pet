## 新增回归重点

- 主页结果操作、快捷入口与状态使用独立行，结果区有受限高度下的最小空间。
- 标题栏控制 36×36、快捷管理 24×24 且静止可见，失效状态有警示图形与自动化名称。
- 搜索框/结果上下键方法、搜索内 Esc、`Ctrl+L`、`Alt+1`～`Alt+4` 与直接页索引。
- 待办手动路径前置、AI/今日安排 Expander 默认及自动展开、折叠控件实例化、编辑焦点入口。
- 设置五项目录、滚动焦点、AI 展开与未保存取消保护。
- 缓存重建危险样式、明确后果、默认保留按钮和原清理范围不变。

## 发布阻断项

1. 在可前台激活应用的解锁 Windows 桌面重跑独立 UI 与强制性能测试。
2. 在受控设备完成物理多屏/缩放、热插拔、休眠/恢复、时区/时钟、Explorer 重启和 0.18.1 → 0.19.0 覆盖升级。
3. 配置受保护代码签名证书并验证安装器、便携主程序、安装后主程序和卸载器。
4. 提交源码后从干净提交重新测试、打包和取证；推送 main/标签、创建 Release、上传后重新下载并核对远端字节。

任一阻断项未满足时，不得将 0.19.0 描述为稳定发布。
