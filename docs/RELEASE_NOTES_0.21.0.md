# Windows AI Desktop Pet 0.21.0 候选说明

日期：2026-09-13。0.21.0 是“键盘与可恢复任务流”候选版本，不是已发布的稳定 Release。

## 本版变化

- 工具窗增加 `Ctrl+N`、`Ctrl+Enter` 和 `F1`，页签显示快捷键提示，Esc 先处理待办编辑或搜索再收起。
- 搜索无结果可一次重置查询/类别/范围或进入授权管理；结果数量和选中序号独立更新。
- 待办增加筛选摘要、上下文空状态、编辑未保存状态与页内放弃确认。
- 手动新建、修改、完成、恢复、稍后、取消提醒和删除统一支持最近一次撤销；撤销拒绝覆盖后续变更，删除改为可恢复的直接操作。
- 今日安排可选前 12 条或清除选择；紧凑按钮至少 36 DIP，时间输入明示 24 小时 `HH:mm`。
- 页签、快捷入口、搜索数量、待办/提醒状态与维护结果增加可访问名称和动态播报；维护失败不显示原异常或完整路径。

## 升级与兼容

- 设置 schema 保持 5，待办 schema 保持 4，快捷入口 schema 保持 1，不新增数据迁移确认。
- 编辑基线、最近撤销、筛选/结果摘要和维护状态都只在进程内保留。
- 撤销恢复待办数据，不回滚已经投递的 Windows 通知历史。
- 不新增外部依赖、网络权限、云同步或遥测。

## 发布边界

候选测试、资产哈希和 PASS/FAIL/SKIP 见[0.21.0 验证报告](release/0.21.0-test-report.md)。前台真实 UI、性能、代码签名、物理多屏/缩放、休眠/时区、Explorer 重启、真实覆盖升级、提交/推送和远端 Release 必须分别验证；任一必需门禁不完整时不得发布为稳定版本。
