# 已有功能优化

基线：0.17.0，2026-09-11。本文根据当前源码、测试和用户入口重新核对，只记录已有功能的完善状态；实施顺序见[0.17.0－功能扩展计划](0.17.0－功能扩展计划.md)。

## 已完成的本轮优化

| 编号 | 已有功能 | 0.17.0 优化结果 | 自动化关注点 |
| :--- | :--- | :--- | :--- |
| SRCH-170-01 | 授权索引 | 在名称索引旁加入默认关闭的 `.txt`/`.md` 正文暂存与原子提交，限制编码、大小、数量、总量和链接 | 解码/二进制/上限、取消、撤销代次、watcher |
| SRCH-170-02 | 搜索结果 | 普通文字可补充正文命中，元数据分值更高；仅正文命中显示短摘要和明确原因 | 排名、摘要长度、范围/类别/分页、模式分流 |
| SRCH-170-03 | 搜索设置 | 原搜索范围卡片内提供单独同意、统计、重建和停用清除；首页说明随状态变化 | 持久化、即时生效、键盘、UIA live region |
| SRCH-170-04 | 隐私与维护 | 正文索引仍是本地派生 SQLite，停用或移除范围清除，不进入备份、诊断、日志和 AI | 备份排除、稳定统计、维护清理 |

## 已有功能现状

| 模块 | 当前状态 | 仍需外部环境确认 |
| :--- | :--- | :--- |
| 桌宠/工具窗 | 四个 RGS 角色、四页紧凑工具窗、常驻/置顶、页内选择、托盘和离线帮助 | 真实桌面鼠标/键盘、多个缩放与多屏 |
| 搜索/快捷入口 | 授权名称/路径索引、可选受控正文、摘要、分页固定、监听重建、分组排序和批量恢复 | 大型真实目录正文资源、长期监听、Explorer 重启 |
| 待办/提醒 | 六种筛选、重复/多次提醒、今日安排、通知中心、稍后和静默 | 休眠/时区切换、系统通知抑制 |
| AI | 多配置、能力验证、单项草稿、完整含 Key 加密迁移、今日安排 | 真实供应商的模型差异与额度条件 |
| 维护/更新 | 事务恢复、每日备份、诊断、缓存清理、GitHub Release 检查与校验下载 | 正式签名、真实覆盖升级和受限网络 |

## 当前质量边界

进程内自动化、合成测量和静态渲染不能代替真实桌面或物理设备。所有发布结论以[0.17.0 验证报告](release/0.17.0-test-report.md)为准；任何 UI、性能、签名或硬件门禁出现 FAIL/SKIP 时，本版本只保留为候选，不作为稳定 Release。
