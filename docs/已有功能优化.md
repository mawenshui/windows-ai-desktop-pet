# 已有功能优化

基线：0.16.1，2026-09-09。本文根据当前源码、测试和用户入口重新核对，只记录已有功能的完善状态；实施顺序见[0.16.1－功能扩展计划](0.16.1－功能扩展计划.md)。

## 已完成的本轮优化

| 编号 | 已有功能 | 0.16.1 优化结果 | 自动化关注点 |
| :--- | :--- | :--- | :--- |
| OPT-161-01 | 今日安排 | 未选中待办的今日时间块合并为匿名占用段；本地和 AI 草稿均避让，不发送其 ID、标题或备注 | 匿名请求字段、AI 冲突拒绝、本地跳段 |
| OPT-161-02 | 本地安排 | 从严格晚于当前时间的精确下一刻钟开始，清除秒和更小精度；草稿提示避让数量 | 秒/毫秒边界、空闲时间不足 |
| OPT-161-03 | 批量应用/撤销 | 两条路径继续整批原子写入；应用过期提示重新生成，撤销过期提示不覆盖后续编辑 | 不发生部分写入、错误语义分离 |
| OPT-161-04 | GitHub 在线更新 | 未保存令牌不参与请求；只读取凭据库；失败或取消保留已发现版本，明确最新才清除 | 未保存/已保存令牌、失败恢复、最新清除 |
| OPT-UI-01 | 工具窗说明 | 保留原卡片和按钮，不新增入口；补充匿名占用时间、避让数量和令牌保存语义 | XAML 结构、键盘与 UIA 回归 |

## 当前质量边界

进程内自动化、合成测量和静态渲染不能代替真实桌面或物理设备。所有发布结论以[0.16.1 验证报告](release/0.16.1-test-report.md)为准；任何 UI、性能、签名或硬件门禁出现 FAIL/SKIP 时，本版本只保留为候选，不创建正式标签或 GitHub Release。
