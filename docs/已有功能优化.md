# 已有功能优化

基线：0.18.0，2026-09-12。本文根据当前源码、测试和用户入口重新核对，只记录已有功能的完善状态；实施顺序见[0.18.0－功能扩展计划](0.18.0－功能扩展计划.md)。

## 已完成的本轮优化

| 编号 | 已有功能 | 0.18.0 优化结果 | 自动化关注点 |
| :--- | :--- | :--- | :--- |
| SRCH-180-01 | 搜索结果 | 列表选择双向绑定，选中后显示名称/类型/大小和四项可见操作，保留双击/Enter | 选择、命令、按钮高度、UIA 名称 |
| SRCH-180-02 | 系统动作 | 打开、资源管理器定位和剪贴板通过独立适配器执行；路径按单参数传递，异常使用稳定提示 | 中文/空格/特殊字符路径、异常隔离 |
| SRCH-180-03 | 搜索到快捷入口 | 结果可直接复用现有快捷存储、默认名称、类型识别和去重；失效目标仍可复制路径 | 文件/文件夹、重复、失效命令状态 |
| SRCH-180-04 | 选择状态 | 相同查询刷新按范围与路径恢复；关键词及查询条件变化立即清除旧选择 | 手动刷新、条件变化、结果消失 |

## 当前质量边界

进程内自动化、合成测量和静态渲染不能代替真实桌面或物理设备。所有发布结论以[0.18.0 验证报告](release/0.18.0-test-report.md)为准；任何 UI、性能、签名或硬件门禁出现 FAIL/SKIP 时，本版本只保留为候选，不作为稳定 Release。
