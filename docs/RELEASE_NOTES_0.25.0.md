# Windows AI Desktop Pet 0.25.0

发布日期：待正式发布确认。本项目不提供 Alpha、Beta、RC、Preview 或 GitHub Pre-release；只有全部门禁满足后创建的普通正式 Release 才代表可公开下载版本。

## 本版新增

- 待办页新增“专注陪伴”：15、25、50 分钟快捷值，5～180 分钟自定义值，可关联当前未完成待办或独立开始。
- 专注会话支持暂停、继续、提前结束确认和正常到时；任何结果都不会自动完成关联待办。
- 复盘与 Markdown 增加本地专注次数、总时长和提前结束次数。
- 专注运行或暂停时，桌宠停止自主漫游、随机气泡和鼠标朝向；正式提醒仍可显示。
- 设置增加“专注时允许点击穿透”和“其他应用同屏全屏时隐藏桌宠”，两项默认关闭并显式保存。
- 托盘增加暂停/继续、结束专注和恢复桌宠交互入口。
- 四个内置 RGS 角色改为真实首帧卡片，显示中文名、选中状态、CC0-1.0 信息与本地许可入口。

## 数据与隐私

- 设置升级到 schema 6；新增字段默认关闭，迁移前保留 `.pre-v6.bak`。
- 新增 `focus-sessions.json` schema 1，具备 revision、原子替换、`.previous`、16 MiB/10,000 条上限和损坏写保护。
- 专注记录进入手动备份、每日自动备份、恢复事务、回滚和明确卸载清理。
- 专注记录只保存可选 Todo ID，不复制标题或备注；不进入 AI、搜索索引、默认日志、诊断或遥测。
- 全屏检测只读取窗口几何与可见状态，不读取标题、正文、进程路径、截图、剪贴板或输入内容。

## 升级说明

- 0.24.0 的设置、待办、提醒、复盘、快捷入口和 AI 配置均保持兼容。
- 低打扰开关默认关闭；升级后不会突然让桌宠穿透或因全屏自动隐藏。
- 便携版与安装版仍默认共用当前 Windows 账户数据；普通维护备份不包含 API Key。

## 已知验证边界
