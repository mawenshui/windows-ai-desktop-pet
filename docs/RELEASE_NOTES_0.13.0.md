## 新增与改进

## 升级与数据

- todos schema 3 保存规则锚点/时区/排队状态，升级前 .pre-v3.bak；旧无时区规则保持固定偏移，普通一次性语义保留。
- 备份 v2 含 SHA-256，不含 Key，不复制活跃索引；待办/队列及快捷项/图标成组处理。恢复确认后退出，下次启动切换；失败/中断有快照回滚。
- 配置导入不替换活动项、不发送请求，需重新配置 Key 并验证。
- 交互卸载默认保留，显式选择才清理已识别数据及已记录凭据；静默保留。先备份有价值的个人数据。
- 提醒“已提交”不表示已展示/已读，退出后没有进程外准点提醒。
