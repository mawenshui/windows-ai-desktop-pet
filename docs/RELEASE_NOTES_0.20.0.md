# Windows AI Desktop Pet 0.20.0 候选说明

日期：2026-09-13。0.20.0 是“智能更新与设置减负”候选版本，不是已发布的稳定 Release。

## 本版变化

- 内置 GitHub 更新分级线路：元数据优先官方、失败自动切换；安装器依次尝试三条内置线路并回退官方地址。
- 更新设置不再要求用户填写 `{url}` 模板、代理地址或 GitHub Token，只保留周期、间隔、检查、下载和可见的“智能线路”状态。
- 更新请求固定为公开仓库并保持匿名；旧加速模板兼容读取后清空，旧更新凭据不再读取或发送。
- Release 解析使用规范化 `browser_download_url`、资产大小和可选 `sha256:` digest，继续以 `SHA256SUMS.txt` 和本地文件哈希作为下载校验。
- 收紧仓库、标签、文件名、HTTPS、用户信息、重定向主机、响应大小和临时文件边界；失败不会清除已发现版本。

## 升级与兼容

- 设置 schema 保持 5，待办 schema 保持 4，不新增数据迁移确认。
- 旧 `accelerationTemplate` 字段仍可反序列化，但规范化后为空，运行时不再使用。
- 旧版更新凭据不会被静默删除，只在用户明确选择卸载并清理个人数据时沿原路径清理。
- 更新仍不会自动安装；校验完成后必须由用户确认才启动安装器并退出应用。

## 发布边界

候选测试、资产哈希和 PASS/FAIL/SKIP 见[0.20.0 验证报告](release/0.20.0-test-report.md)。前台真实 UI、性能、代码签名、物理多屏/缩放、休眠/时区、Explorer 重启、真实覆盖升级、提交/推送和远端 Release 必须分别验证；任一必需门禁不完整时不得发布为稳定版本。
